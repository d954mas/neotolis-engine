# Песнь Тамги — план арта/визуала

Что нужно нарисовать и подключить, чтобы игра перестала показывать «квадраты».
Источник правды по тайлам — `config/tiles.tsv`. Стиль — существующий `raw/` (расписной
пустынный иллюстрейт, тёплая палитра, мягкие края, песочная подложка, ~128px, без жёсткого контура).

## Как ассет попадает в игру (5 шагов на каждый спрайт)

1. **PNG** → `raw/<категория>/<имя>.png` (это делает Codex).
2. **build_packs.c** → строка `{"<кат>", "raw/.../имя.png", "region_name", 0.5, 0.5}` в нужный батч.
   Билдер пакует в `turkic_jam.ntpack` и генерит конст `ASSET_ATLAS_REGION_..._REGION_NAME`.
   (Прозрачный/пустой PNG билдер пропускает как INVALID → снова квадрат.)
3. **game.h** → поле `uint32_t <handle>;`.
4. **main.c** → `TJ_FIND_REGION("region_name", ASSET_...);` — резолв хэндла из атласа.
5. **view.c** → маппинг id тайла → хэндл в `tile_region_for_id` (карта) и `card_art_region_for_id` (лицо карты).

Шаги 2–5 — моя работа (код). Шаг 1 — Codex. Пересборка пака:
`cmake --build build/_cmake/native-debug --target build_turkic_jam_packs` затем запустить
`build_turkic_jam_packs.exe build/games/turkic-jam-2026`, потом обычная сборка игры.

## Что уже есть (реальный арт, не плейсхолдеры)

Подключено и работает: земля/декор/дорога/буферы, аул (5 стадий + юрты/огонь/тамга),
герой-странник (ходьба N/S/E/W + idle + панель), UI (карты back/playable/selected, панели,
чипы, оверлеи клеток, кнопка), иконки (стат/ресурс/круг/день…), FX (пыль/плейс/триггер/попап…),
**3 врага** (`wolf_track`=следы, `mirage`, `storm`) — рисуются на дороге и в окне боя.

## Главная дыра — 15 тайлов мерджа (это и есть «квадраты»)

5 линий × 3 тира. У них нет ни арта, ни маппинга id → падают в `cell_color()` (цветной квадрат).

| Линия | tier1 | tier2 | tier3 | бонус |
|---|---|---|---|---|
| Война (body) | Точило | Кузня | Арсенал | +Сила |
| Табун (mind) | Коновязь | Табун | Орда | +Скорость |
| Степь (spirit)| Привал | Стан | Твердыня | +Выносл/ХП |
| Жильё | Саксаул | Юрта | Аул-стоянка | припасы/круг |
| Вода | Лужа | Родник | Озеро жизни | хил/круг |

**Читаемость тира:** имена уже кодируют рост (мелкое→крупное). Поверх арта добавлю в КОДЕ
бейдж тира (1/2/3 точками или числом на углу тайла/карты) — чтобы уровень читался гарантированно,
не завися от тонкостей рисунка. Это дешёвая страховка.

## Приоритеты для Codex (новый арт)

- **A1 — Война ×3** (Точило → Кузня → Арсенал): tile 128 + card 64. Кузнечная тема, рост размера.
- **A2 — Табун ×3** (Коновязь → Табун → Орда): tile 128 + card 64. Кони/коновязь → много коней.
- **A3 — добивка линий** (Степь tier3 Твердыня, Вода ×3 «родные», Жильё tier3): чтобы все 15 были авторские.
- **B — Боссы/элиты:** сейчас это те же 3 врага, увеличенные. Нужны: Толстяк 🗿, Шустрый ⚡,
  Лютый 💢 (узнаваемые силуэты) + финальный именной «Хранитель Кольца». Крупные ~160px.
- **C — UI-полиш:** грани кубика d4/d6/d8/d10/d12/d20 (анимация события), мешочек (закрытый +
  кадры открытия), иконки событий (буря/завал/погоня), иконки веток аула (Сила/Скорость/Выносл/Наследие).
- **D — маркеры клеток:** сейчас событие = синий квадрат, привал = зелёный. Нужны мелкие иконки
  (знак вопроса/кубик для события, костёр для привала).

## Решения (зафиксированы 2026-06-07)

1. **Враги — настоящие существа.** Перерисовать 3 врага в узнаваемых тварей:
   `wolf_track` → степной **волк/зверь**, `mirage` → **мираж-тварь** (морок), `storm` → **песчаный элементаль/дух бури**.
   Имена файлов сохраняем (overwrite) → нулевое переподключение в коде.
2. **Все 15 тайлов мерджа — авторские.** Codex рисует каждую линию×тир с нуля (переиспользование — только
   временный плейсхолдер, пока арт не пришёл).
3. **Боссы — отдельный арт.** Уникальные силуэты Толстяк/Шустрый/Лютый + именной финальный «Хранитель Кольца».

## Контракт имён/размеров для Codex

Один спрайт на тайл — он же на карте (рисуется ~128) и на лице карты (рисуется ~64). PNG с альфой,
**видимые пиксели обязательны** (прозрачный = билдер пропустит). Стиль = существующий `raw/tiles/*`.

**Тайлы мерджа** → `raw/tiles/tile_<id>.png`, **128×128**, id из `tiles.tsv`:
`tile_war_1..3`, `tile_horse_1..3`, `tile_steppe_1..3`, `tile_home_1..3`, `tile_water_1..3` (15 шт).
Тир читается ростом объекта (имена это задают). Бейдж уровня (1/2/3) дорисую в КОДЕ — арт его не несёт.

**Враги-существа** → overwrite существующих, **128×128**:
`raw/tiles/tile_wolf_track_01.png`, `tile_mirage_01.png`, `tile_storm_01.png`. По возможности +hit-кадр позже.

**Боссы** → `raw/enemies/boss_fat.png`, `boss_swift.png`, `boss_fierce.png`, `boss_ring_keeper.png`,
**~160×160** (крупнее рядовых). Узнаваемые архетипы.

**UI-полиш (батч C, позже):** грани кубика `raw/ui/die_d{4,6,8,10,12,20}.png` (или один d-набор),
мешочек `raw/ui/pouch_closed.png` + кадры открытия, иконки событий `raw/icons/ev_*.png`,
иконки веток аула `raw/icons/aul_force|speed|vigor|keep_32.png`.

**Контакт-шит:** на каждую партию класть `raw/_review/<batch>_sheet.png` для быстрой приёмки.

## Разделение труда

- **Codex:** рисует PNG по контракту, отвечает в `FROM_GDD.md`, кладёт contact-sheet.
- **Я (код):** на каждый пришедший спрайт делаю шаги 2–5; делаю бейдж тира; код выбора спрайта босса
  по архетипу; пересобираю пак и проверяю в игре. Процедурный/SVG-арт не делаем — весь арт от Codex.
- **Хэндофф-бриф для Codex:** `coordination/ART_BRIEF.md` (самодостаточный, копипастится Codex'у).
