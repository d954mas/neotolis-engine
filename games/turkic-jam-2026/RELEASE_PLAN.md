# Прототип → релиз: план

Цель: из работающего прототипа сделать игру, понятную и сочную с первых секунд.
Ветка `release-polish` (worktree). Арт генерится параллельно в основном дереве — мерджим позже.
Здесь — только код/дизайн, не зависящий от нового арта.

## P1 — FTUE / обучение (приоритет 1, главный блокер)

Игра бросает игрока в забег без объяснений. Нужен **поэтапный first-run туториал**:
шаги по одному, подсветка нужного элемента, остальное приглушено, ждём действие игрока.

Шаги (только первый забег, флаг `ftue_done` в save, кнопка «Пропустить»):
1. «Герой идёт и сражается сам» — стрелка на героя, пауза ~2с / тап.
2. «Нажми Мешочек — вытяни карту» — подсветка мешочка, ждём pull.
3. «Перетащи карту на зелёную клетку» — подсветка поля, ждём place.
4. «Собери 3 рядом — слияние усилит героя» — выдать 2 такие же, ждём merge, показать +стат.
5. «Дальше — выживай и бей босса. Удачи!» — конец FTUE.

Механика: FTUE-контроллер в сцене читает состояние run (pouch/hand/field/merge-флаг),
гейтит шаги, рисует оверлей подсветки+текста. Авто-ход можно притормозить на шагах 1–4.

## P2 — Сочность и анимации (приоритет 2)

- Герой: анимация ходьбы (кадры N/S/E/W уже есть — проигрывать по фазе шага), лёгкий «боб».
- Бой: импульс на удар (масштаб/сдвиг спрайта), всплывающие цифры урона (есть — усилить), вспышка.
- Мердж: burst-вспышка + поп масштабом нового тайла (fx_merge_* придёт от Codex).
- Карта: твин полёта карты в клетку (ease), приземление-«поп».
- Кубик события: анимированный бросок (грани) перед результатом.
- Установка тайла: пыль/поп (fx_tile_placed_* есть).
- Ресурсы/HP: тик-анимация чисел, всплывашки «+N припасов».
- Камера: мягкий зум/нудж на ключевых событиях (без тряски — её убрали намеренно).
- Звук — в отдельном worktree `audio-system`, здесь не трогаем.

## P3 — Баланс (приоритет 3)

- Потолок макс-билда плоский (урон только от финального босса) — поднять поздние круги
  (`enemy_scale_per_circle_pct` / урезать `rest_heal_pct`), чтобы и сильный билд потел на 8–10.
- Первый забег: дать чуть больше воздуха новичку (учится строить во время FTUE).
- Пейсинг авто-хода (`move_seconds_per_cell`) — проверить, не скучно/не суетно.

## P4 — Релизный лоск (приоритет 4)

- Победа (круг 10): достойный финальный экран/анимация, не только текст.
- Крайние состояния: пустой мешочек, полная рука, поле забито — понятные подсказки.
- Читаемость: бейдж тира на тайлах, понятные маркеры события/привала.
- Язык: RU/EN/TR — проверить покрытие новых строк FTUE.

## Порядок

P1 (FTUE) → P2 (juice/анимации) → P3 (баланс) → P4 (лоск). Тестирую через devapi + dump-frame,
коммичу партиями. Слияние с арт-веткой — когда Codex сдаст партии.
