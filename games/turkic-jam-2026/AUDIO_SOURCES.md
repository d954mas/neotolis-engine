# Audio sources — CC0 / CC-BY (Песнь Тамги)

Curated free, legally-usable music + SFX for the desert/Turkic/nomad mood. Every item is
**CC0** (no attribution) or **CC-BY** (attribution required). Licenses verified per-item on
the source page. Items marked **VERIFY** need a last per-track license check before shipping.

> **Pixabay caveat:** Pixabay's Content License allows commercial use w/o attribution, but
> forbids redistributing the audio as a standalone file. Embedding inside the game is fine
> (intended use), but it is NOT CC0 — for zero ambiguity on itch.io prefer the CC0/CC-BY
> freesound/OGA/incompetech items. Pixabay entries tagged **[Pixabay-license]**.
> **nt_audio expects loose WAV/MP3** (miniaudio, native+web) — convert the one OGG pick to WAV/MP3.

## Recommended minimal set (least licensing surface, cohesive)
- Title: **Mystery Bazaar (Slower)** — Kevin MacLeod — CC-BY
- Gameplay loop: **Desert theme** — yd — CC0
- Boss: **Desert City** (CC-BY) or **Dark Shrine Loop** (CC0)
- SFX: all CC0 below → only 1-2 attributions total.
- Palette note: incompetech tracks lean santur/Middle-Eastern (bazaar-ish). Truest Central-Asian
  fit = Pixabay morin-khuur/jaw-harp folk (kobyz/khomus equivalents) + yd's sparse *Desert theme*.
