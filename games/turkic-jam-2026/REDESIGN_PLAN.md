## Видение

Тюркский авто-мердж-роуглайт: **Loop Hero (поле = билд, дорога = авто-бой)** ×
**Capybara Go (плотный ритм действия)**. Главная боль текущей сборки — **пустота**
(почти пустые клетки). Лечится тем, что **авто-бой = пульс лупа**, дорога плотная,
а поле — мердж-билд, который качает героя.

## Кор-петли

- **10 сек:** герой идёт → клетка-действие (бой / событие / мелочь) → лут в мешочек.
- **Круг:** разгон → элита (середина) → разгон → **БОСС (последняя клетка)** → большой мешочек → новый круг. 10 кругов = победа.
- **Мета:** умер → припасы в аул → прокачка аула → следующий чемпион рода сильнее.

## Системы (залочено)

- **Статы (3):** 💪 Сила = урон/удар; 🐎 Скорость = частота атак (интервал = БАЗА/скорость);
  🛡️ Выносливость = макс. ХП + плоская защита. `stamina` = ХП.
- **Бой:** авто, герой тормозит на клетке врага, ATB по скорости, детерминированный
  (без уворота), можно умереть. Враг = ХП / урон / скорость (+ архетип у боссов).
- **Дорога:** каждый шаг — действие; 3-й = бой; 5-й = событие; середина = элита;
  последняя = босс; шаг 15 = элита+. Пустых клеток нет (мелочь = монетка/флавор).
- **События (кубик):** `эффект = стат × множитель`. Кубик = **сам стат** (грани = стату,
  d(стат)), бросок против кубика/порога события. Низкие ставки. Advantage когда сильно
  выше тира, авто-проход когда «перерос». Бой — без кубика (надёжный экзамен билда).
- **Поле = билд:** 5 линий мерджа: Война→Сила, Табун→Скорость, Степь→Выносливость,
  Жильё→припасы (доход/круг), Вода→хил (доход/круг). Боевые линии живут **пока стоят**.
- **Мердж:** 3 связкой (ортогонально, тот же тип+тир), **авто**, каскад. Двигать
  свободно, **сносить нельзя**. Поле просторное. Тир-ап даёт >3× и освобождает клетки.
- **Карты/мешочек:** дроп копится в **мешочек**, тап → ревил карты + лог → в руку
  (рука **бесконечная**, веер стопок по типу+тиру). Краны: бой (часто), событие-успех
  (иногда), старт, **круг = большой мешочек**, босс = больше. Дроп **количеством**;
  пол тира растёт ступенями (круг 4-6 → тир-2, 7-10 → тир-3); джекпоты не сыплем.
  Удача (аул) = шанс +1 тир. Концентрированный пул линий на круг.
- **Валюта:** одна — **припасы** (wisdom/glory вырезаны). Банк в аул при смерти.
- **Аул (мета):** прокачка за припасы. Ядро: +старт Сила/Скорость/Выносливость,
  +стартовый мешочек, наследие (банк %). Перки заменяют классы (крит / первый удар /
  вампиризм / x2 доход / дух предка = воскрес 1/забег). Если время: удача, 3x скорость.
  Стадия аула (арт camp→capital уже есть) растёт от суммы вложений.
- **Герой:** один, классов нет. Кастомизация = перки аула. «Чемпион рода».
- **Боссы:** 3 архетипа (🗿 Толстяк=ХП / ⚡ Шустрый=скорость / 💢 Лютый=урон), давят на
  стат. Телеграф заранее. Ротация ранних кругов. Передышка-хил перед боссом. Финал
  (круг 10) — именной мульти-архетип.

## Формулы (дефолты в config.c; крутятся в balance.ini)

```
Урон        = 1 + Сила
Макс. ХП    = start_stamina + Выносливость * vit_hp_mul
Защита      = Выносливость * vit_def_mul         (плоский вычет, мин 0 урона)
Интервал атаки (с) = atk_base / (1 + Скорость * spd_mul)
Событие: roll(d = стат-грани) , эффект = база * (1 + dice_coeff * roll)
   нат-1 фейл, нат-макс пасс; перерос (стат >= тир*K) → авто
DC события  = ev_dc_base + ev_dc_per_circle * circle
Босс/элита  HP/урон/скорость = base * (1 + per_circle*circle), архетип множит свой стат
```
