# 09. Действия игрока и playable loop

## Главная формула

```text
Герой идет сам.
Игрок не управляет шагами героя.
Игрок управляет пустыней, картами, риском, аулом и следующим наследником.
```

Игрок должен чувствовать, что он не зритель. Он помогает путнику идти дальше, но не спасает его руками в моменте.

## Базовый loop одного забега

1. Игрок выбирает наследника.
2. Наследник выходит из аула.
3. Наследник автоматически идет по кольцевой дороге.
4. На клетках дороги происходят авто-события:
   - получение ресурса;
   - проверка;
   - потеря или восстановление Сил;
   - шанс получить карту.
5. Игрок получает карты.
6. Игрок ставит карты в пустынные buildable-ячейки: ближние `roadside` и дальние `field`.
7. Поставленные тайлы меняют будущие проходы героя:
   - помогают восстановиться;
   - дают ресурсы;
   - создают риск;
   - открывают синергии.
8. Герой доходит до аула и завершает круг.
9. Игрок получает выбор карты или улучшения.
10. Следующий круг становится опаснее.
11. Герой либо проходит 10 кругов, либо умирает.

## Что игрок делает во время движения

Игрок:

- смотрит, какие клетки впереди;
- решает, стоит ли ставить карту сейчас;
- выбирает место для карты;
- сравнивает пользу и риск тайла;
- может держать карту в руке до лучшего момента;
- следит за Силами героя;
- видит, какие ресурсы уже принес забег.

Игрок не делает:

- не двигает героя;
- не выбирает атаку;
- не подтверждает каждую обычную клетку;
- не решает мелкие авто-проверки вручную.

## Когда игра ставит паузу

Пауза нужна только для важных решений.

Игра ставит паузу:

- когда игрок впервые получает обучающую карту;
- когда нужно выбрать 1 карту из 3;
- когда нужно выбрать улучшение;
- при смерти героя;
- при выборе реликта;
- при редком крупном событии.

Обычные клетки не ставят паузу.

## Карты

Карты - главный инструмент игрока.

Герой может найти карту:

- после завершения круга;
- как награду от безопасного тайла;
- как награду за успешную проверку;
- как редкую награду за рискованный тайл.

Для MVP:

```text
после каждого круга: выбор 1 из 3 карт
во время движения: редкий шанс получить карту от события
рука: до 5 карт
лишняя карта: самая старая уходит в сброс
```

## Как карты помогают герою

Игрок ставит карту в пустыню. После этого тайл начинает влиять на будущие проходы или на большой мир вокруг пути.

`roadside`-тайлы ставятся за road buffer и работают на ближайшую дорожную клетку.

`field`-тайлы ставятся дальше от дороги и работают через радиус, соседство, доход за круг, ауры или синергии. Они не обязаны касаться дороги.

Примеры:

| Карта | Что делает |
| --- | --- |
| Саксаул | Первый малый roadside-тайл: тень и хворост, Силы +1, Запасы +1. |
| Оазис | Более редкая сильная помощь: восстанавливает Силы и дает Запасы. |
| Юрта | Field-тайл: экономика, стоянки, синергии. |
| Камень Тамги | Field-тайл: Мудрость, память рода, ауры. |
| Волчий след | Roadside-риск: Body-проверка рядом с маршрутом, Слава. |
| Мираж | Field-риск: Mind-аура, искажение наград/проверок. |
| Песчаная буря | Field-риск: Spirit-зона и большая награда. |

Главная идея:

```text
помочь герою = не убрать опасность,
а построить такой путь, который он сможет выдержать.
```

## Смерть героя

Если Силы падают до 0:

1. Забег заканчивается.
2. На клетке смерти появляется Последняя Тамга.
3. Часть ресурсов уходит в аул.
4. Игрок выбирает реликт или память забега.
5. Игрок может улучшить аул.
6. Новый наследник выходит на путь.

Смерть не должна ощущаться как простой проигрыш. Это часть прогресса рода.

## Loop между забегами

```text
герой идет
-> игрок ставит карты
-> путь становится богаче и опаснее
-> герой приносит ресурсы или умирает
-> аул получает часть результата
-> игрок усиливает род
-> новый герой идет дальше
```

## Что прокачивает аул

Аул использует ресурсы, принесенные или сохраненные после смерти.

Ресурсы:

| Ресурс | Для чего |
| --- | --- |
| Запасы | Практические улучшения, выживание, стартовые бонусы. |
| Мудрость | Память, Тамги, духовные и стратегические улучшения. |
| Слава | Открытие новых наследников, карт, сильных улучшений. |

MVP-апгрейды аула:

| Апгрейд | Эффект |
| --- | --- |
| Охотничий шатер | Охотник сильнее в Body-проверках. |
| Шаманский очаг | Шаман сильнее в Spirit-проверках. |
| Дом сказителя | Сказитель лучше собирает Тамги. |
| Общие запасы | Новый герой начинает с большим запасом Сил. |
| Память рода | После смерти сохраняется больше ресурсов. |

Долгая цель прокачки - рост не только чисел, но и статуса места:

```text
стойбище рода -> родовой аул -> укрепленный аул -> торговое поселение
-> степной город -> восточная столица -> ханство/султанат/каганат
```

В первом playable это пока читается через маленькие признаки:

- больше сохраненных ресурсов;
- новая юрта или огонь в центре;
- сильнее наследники;
- больше памяти о погибших;
- доступ к новым картам.

Позже это может стать отдельным экраном между забегами, но во время пути основной UI должен обслуживать героя, карту, карты тайлов и лог.

## Что дает переход этапа аула

Каждый этап аула должен давать **одну крупную новую возможность**, а не только `+1 к стату`.

| Переход | Визуально | Крупный бонус |
| --- | --- | --- |
| Стойбище -> Родовой аул | Появляется больше юрт, место старейшин, загон. | Выбор наследника перед забегом. |
| Родовой аул -> Укрепленный аул | Вал/частокол, сторожевые огни, мастерская. | Подготовка героя: выбрать стартовый бонус. |
| Укрепленный аул -> Торговое поселение | Караван, рынок, водоем. | Обмен ресурсов и замена одной карты. |
| Торговое поселение -> Степной город | Улицы, святилище Тамги, ремесленные кварталы. | Синергии тайлов и 2 активных реликта. |
| Степной город -> Восточная столица | Двор, архив рода, большие святилища. | Ветки школ/орденов для архетипов наследников. |
| Восточная столица -> Ханство/султанат/каганат | Знамена, вассальные стойбища, караванные пути. | Глобальные модификаторы пустыни и endgame-цели. |

Эти этапы должны работать и как визуализация прогресса, и как изменение правил игры.

## Ответ на главный вопрос

Да, loop именно такой:

```text
Герой сам идет.
Он находит ресурсы и карты.
Игрок использует карты, ставит тайлы и помогает будущим проходам.
Если герой умирает, род получает часть ресурсов и Тамгу.
Игрок прокачивает аул.
Новый герой выходит из аула.
```

Это должно быть первым playable-кором.
