# 24. Narrative designer role

Цель: выделить отдельную роль, которая отвечает за мир, тон, тексты, культурные опоры и понятность истории.

## Зачем нужна роль

GDD сейчас хорошо держит loop, карты, UI и FTUE, но наративный слой нельзя вести случайными красивыми фразами. Игра опирается на тюркско-кочевой образ, род, аул, Тамгу, путь, память и пустыню. Это требует отдельного контроля:

- чтобы текст был коротким и игровым;
- чтобы мифологические мотивы не превращались в произвольную экзотику;
- чтобы аул, путь, смерть и Тамга имели смысл;
- чтобы игрок понимал, что происходит, даже если не знает культурный контекст.

## Название роли

```text
Narrative Designer / Наративный дизайнер
```

Внутри проекта можно коротко называть: **Нарратив**.

## Зона ответственности

| Область | Что делает |
| --- | --- |
| Мир | Формулирует, что такое аул, путь, пустыня, Тамга, род, наследники. |
| Тон | Держит язык: коротко, меланхолично, понятно, без сказочной перегрузки. |
| FTUE | Пишет финальные строки интро, лога, подсказок и результатов. |
| Культурные опоры | Проверяет, какие мотивы можно использовать, а какие лучше не трогать. |
| Термины | Ведет словарь: аул, стойбище, род, Тамга, путник, наследник. |
| События | Пишет тексты для клеток, проверок, риска, смерти, возвращения. |
| Арт-бриф | Объясняет художнику смысл объектов, а не только внешний вид. |

## Чего роль не делает

- Не пишет длинный лор вместо игры.
- Не превращает FTUE в рассказ на несколько экранов.
- Не утверждает сомнительные исторические/мифологические факты без исследования.
- Не добавляет арабскую сказочность, дворцы, джиннов, лампы, ковры, базарную экзотику.
- Не использует реальные священные/ритуальные элементы как декор без проверки.

## Правило культурного ресерча

Если текст или арт ссылается на конкретный тюркский миф, обряд, имя, существо, символ или историческую практику, нужно:

1. найти источник;
2. понять, это общий мотив или конкретная традиция одного народа/региона;
3. решить, используем прямую ссылку или делаем вдохновленный вымышленный мотив;
4. записать это в GDD.

Для джема безопаснее использовать **вымышленный мир, вдохновленный мотивами**, а не заявлять историческую точность.

## Тон игры

Ключевые слова:

```text
род
путь
песок
след
костер
имя
память
знак
ветер
возвращение
наследник
```

Не использовать как основной тон:

```text
пророчество
магический султан
джинн
золотой дворец
сказочный базар
экзотический восток
```

## Принцип текста

Текст должен отвечать на один из трех вопросов:

1. Что сейчас произошло?
2. Почему это важно?
3. Что игроку делать дальше?

Если строка не отвечает ни на один вопрос, ее лучше убрать.

## Форматы текста

### Интро

2-3 короткие строки. Не больше 8-10 секунд вместе с анимацией.

### Лог

Одна строка, факт + результат:

```text
Саксаул: путник находит тень и хворост. Силы +1. Запасы +1.
```

### Подсказка

Одна задача:

```text
Поставь Саксаул в подсвеченную клетку.
```

### Итог

Причина + сохранение:

```text
Аул сохраняет путь: Запасы +2. Память +1.
```

## Первый словарь

| Термин | Рабочее значение |
| --- | --- |
| Аул | Центр рода, дом, постоянная база. В начале ближе к стойбищу, потом растет. |
| Стойбище | Самая ранняя форма аула: костер, 2-3 юрты, мало постоянных построек. |
| Род | Люди за путником. Они помнят погибших и сохраняют часть результата. |
| Путник | Первый архетипический герой FTUE. Не личное имя. |
| Наследник | Следующий герой после смерти/попытки. |
| Тамга | Знак памяти и след попытки. Не просто loot. |
| Последняя Тамга | След погибшего/почти погибшего путника, цель для следующего. |
| Путь | Дорога-loop вокруг аула. |

## FTUE step 1: narrative goal

Шаг 1 не должен объяснять мифологию. Он должен дать чувство:

```text
есть род
есть дом
есть путь
первый путник выходит
```

## FTUE step 1: pacing

Главный риск: игрок может раздражаться, если первые секунды выглядят как длинная заставка до игры. Поэтому интро должно быть коротким и живым.

Правило:

```text
6 секунд максимум до появления/подъема первого путника
после первого шага путника это уже gameplay, не заставка
skip/click/Space ускоряет, но не ломает переход
каждые 1-1.5 секунды появляется новый визуальный сигнал
```

Интро не должно быть просто текстом на черном экране. Это reveal-сцена:

```text
темнота
-> песок/ветер
-> огонек костра
-> силуэты юрт
-> кромка дороги
-> первый путник
-> начало движения
```

Аул не возникает магически. Он уже был здесь. Тьма, песок и камера постепенно открывают его игроку.

## FTUE step 1: timing target

| Время | Что происходит | Зачем |
| --- | --- | --- |
| 0.0 | Темный экран, слышен ветер. | Мгновенный тон. |
| 0.4 | Появляется песок в воздухе, не статичная чернота. | Экран уже живой. |
| 0.8 | Текст `Песок стирает следы.` | Первая тема: следы исчезают. |
| 1.8 | В темноте проступает слабый огонь. | Игрок видит цель взгляда. |
| 2.3 | Текст `Путь ждет первого путника.` | Сразу дает сказочный импульс через дорогу, которую открывает аул. |
| 3.1 | Огонь становится ярче, проявляются 2-3 юрты. | Аул был здесь, он открывается. |
| 4.0 | Камера чуть отъезжает, видна кромка дороги. | Путь вокруг аула. |
| 4.8 | У костра виден первый путник, костер мягко пульсирует. | Появляется субъект действия и readiness target. |
| 5.4 | Игрок нажимает костер/аул/`В путь`; путник делает первый шаг к дороге. | Gameplay уже начался: карта живая, герой в мире. |
| 6.0 | HUD/лог включаются мягко, путник идет к `road_entry`. | Игрок наблюдает автодвижение, input ограничен. |

Путь от костра до дороги - это не заставка. Это **первый gameplay-state с locked input**:

```text
игра уже показывает карту
герой уже в игровом мире
камера уже работает
лог/панель могут появляться
игрок еще не управляет, потому что FTUE учит: герой идет сам
```

Readiness action:

```text
игрок нажимает костер / аул / "В путь"
```

Это не команда путнику и не управление движением. Это подтверждение готовности игрока начать путь от имени рода. После этого путник идет сам.

Чтобы игрок не пропустил действие, над аулом/костром появляется анимированный палец-указатель и короткая подпись:

```text
Отправиться в путь
```

Палец мягко подпрыгивает/пульсирует. Подсказка должна быть заметной, но не перекрывать аул.

Если игрок бездействует, костер пульсирует и подсказка становится чуть заметнее. Автостарт допустим только как fallback через 8-10 секунд.

Если игрок кликает/жмет `Space`:

```text
ускорить текущую фазу reveal
сохранить ключевые кадры: костер -> аул -> путник
не делать резкий cut из черноты сразу в gameplay
```

Production baseline:

```text
Песок стирает следы.
Путь ждет первого путника.
Отправиться в путь.
Первый путник выходит из аула.
Путь ведет его сам.
```

`Род хранит имена` сохраняем для момента смерти, Тамги или результата забега. В первом клике важнее экранное действие: аул, костер, путник, путь.

## Варианты текста для FTUE step 1

### Вариант A: максимально ясный

```text
Песок стирает следы.
У костра ждет первый путник.
Отправиться в путь.
Первый путник выходит из аула.
```

Плюс: понятно. Минус: мало уникального вкуса.

### Вариант B: production baseline / игра-сказка

```text
Песок стирает следы.
Путь ждет первого путника.
Отправиться в путь.
Первый путник выходит из аула.
Путь ведет его сам.
```

Плюс: сразу звучит как начало сказки и направляет внимание к дороге. Минус: чуть менее буквально связано с кадром костра, поэтому анимация должна быстро показать кромку пути.

### Вариант C: родовая сказка

```text
Песок стирает следы.
Род хранит имена у огня.
Отправиться в путь.
Он выходит из аула. За спиной остается род.
```

Плюс: сильнее тема памяти. Минус: слишком абстрактно до Тамги.

### Вариант D: более игровой

```text
Аул - начало пути.
Путник выйдет сам.
Начать путь.
Путь ведет его сам.
```

Плюс: сразу связывает путь и loop. Минус: меньше поэзии.

## Рекомендация на сейчас

Для первого playable берем Option B:

```text
Песок стирает следы.
Путь ждет первого путника.
Отправиться в путь.
Первый путник выходит из аула.
Путь ведет его сам.
```

Причина: коротко, связано с экранным действием и оставляет `Род хранит имена` для Тамги, где память станет механикой.

## Первые задачи нарратива

1. Проверить и улучшить текст FTUE step 1.
2. Составить словарь мира на 20-30 терминов.
3. Подготовить 10-15 строк лога для первых 10 минут.
4. Найти культурные источники по Тамге, аулу/стойбищу, кочевому пути, памяти рода.
5. Составить список запретов и осторожных тем.
6. Дать art-thread смысловые брифы для: аул, путник, Тамга, Саксаул, Звериная тропа / волчий след как маркер.

## Следующий вопрос для обсуждения

Нужно решить, насколько текст FTUE должен быть:

```text
ясный и почти утилитарный
или
поэтичный, но чуть менее прямой
```

Для джема безопаснее начать с ясного текста и добавлять поэзию только там, где она не мешает действию.
