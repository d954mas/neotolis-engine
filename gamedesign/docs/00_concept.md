# 00. Концепт крупно

## Название

**Песнь Тамги**

## Коротко

Род кочевников заперт в проклятом кольце пустыни. В центре стоит аул. Вокруг аула идет священная дорога. Каждый наследник выходит на эту дорогу и идет по кругу сам.

Игрок не ведет героя руками. Игрок готовит род, выбирает наследника и занимает ячейки пустыни: ближние тайлы у дорожного коридора и дальние тайлы большого мира. Он ставит Саксаулы, юрты, камни Тамги, опасности, Оазисы и знаки памяти.

Цель - провести одного наследника через 10 кругов подряд. Прошлые герои могут погибнуть, но они оставляют Последние Тамги. Будущие наследники находят эти следы и становятся частью общей памяти рода.

## Главная фантазия

Игрок строит не город и не армию. Он строит **память рода**.

Пустыня стирает следы, стоянки и временные постройки. Но род помнит. Каждый погибший наследник оставляет знание. Следующий герой идет дальше благодаря тем, кто погиб до него.

## Референс

Основной референс - **Loop Hero**:

- герой идет автоматически;
- путь замкнутый;
- игрок меняет мир вокруг пути;
- сила мира и опасность растут из тайлов;
- важен ритм "круг -> награда -> решение -> следующий круг".

Отличие от Loop Hero:

- в центре не лагерь как меню, а **аул как визуальное сердце карты**;
- игрок строит **большую пустыню вокруг дорожного коридора**, а не просто абстрактную карту;
- смерть героя оставляет **Последнюю Тамгу**;
- тема не мрачное темное фэнтези, а кочевая память, путь, род и песнь.

## Игровой образ

На экране должен читаться один простой образ:

```text
          пустыня / build slots

      [ ] [ ] [ ] [ ] [ ]
    [ ]  дорога вокруг аула  [ ]
    [ ]       [ АУЛ ]        [ ]
    [ ]  дорога вокруг аула  [ ]
      [ ] [ ] [ ] [ ] [ ]

          пустыня / build slots
```

Аул - центр.  
Дорога - кольцо.  
Пустыня - пространство решений игрока.

## Эмоция

Игра должна ощущаться как:

- путь через опасную, но красивую пустыню;
- род, который теряет людей, но сохраняет знания;
- спокойное стратегическое давление;
- меланхолия без безысходности.

## Ключевая фраза

> Один герой должен пройти путь, но за его спиной стоят все, кто погиб до него.
