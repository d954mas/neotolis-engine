# 05. Арт-дирекшен

## Визуальная цель

Игрок должен с первого взгляда видеть:

- аул в центре;
- дорогу вокруг аула;
- пустыню вокруг дороги;
- занятые и свободные ячейки;
- путь героя;
- места памяти погибших.

## Тон

Тюркско-кочевой тон:

- аул;
- юрты;
- тамги;
- степь и пустыня;
- ветер;
- волк;
- сказители;
- камни памяти;
- костер;
- следы в песке.

Не делать:

- арабский дворец;
- лампы джиннов;
- восточные базары;
- ковровую перегруженность;
- "Алладин"-вайб.

## Палитра

| Роль | Цветовое направление |
| --- | --- |
| Пустыня | песочный, охра, сухая глина |
| Дорога | чуть темнее песка, утоптанная земля |
| Аул | войлок, дерево, приглушенный красный |
| Мудрость / Тамга | бирюзовый, сине-зеленый |
| Опасность | выжженный красный, темный фиолетовый |
| Духи / буря | пыльный белый, серо-синий |

## Стиль

- 2D сверху или легкая изометрия.
- Крупные простые формы.
- Читаемые пиктограммы.
- Минимум мелкой текстуры.
- Силуэт важнее детализации.
- Тайлы должны различаться без чтения текста.

## Иконки MVP

| Объект | Иконка |
| --- | --- |
| Аул | группа юрт вокруг костра. |
| Саксаул | низкий темный куст, сухие ветви, маленькая тень. |
| Оазис | вода и маленький зеленый куст; выглядит заметно ценнее Саксаула. |
| Юрта | белый треугольный силуэт. |
| Камень Тамги | камень с резным знаком. |

| Мираж | волнистый силуэт горизонта. |
| Буря | спираль ветра. |

| Реликт | тот же тайл, но выцветший и потрескавшийся. |

## UI

UI должен быть спокойным и утилитарным:

- верхняя строка ресурсов;
- карточка героя;
- карта/тайл с коротким текстом;
- подсветка доступных пустынных ячеек;
- отдельный экран смерти;
- отдельный экран победы.

Не перегружать декоративными рамками. Джемовый UI должен быть читаемым.
