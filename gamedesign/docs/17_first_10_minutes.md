# 17. Первые 10 минут playable

Цель документа: зафиксировать первый игровой отрезок как проверяемый сценарий, а не как набор отдельных систем. За 10 минут игрок должен увидеть полный core MVP:

```text
интро
-> первый ресурс
-> Саксаул
-> постановка тайла
-> первый круг
-> выбор 1 из 3
-> риск второго круга
-> смерть или почти смерть
-> ресурсы аула
-> новый наследник
-> подбор Тамги
```

Сценарий рассчитан на аул в центре, loop-дорогу вокруг него, автодвижение героя и одну playable-скорость. Конкретная форма дороги берется из `map_*` параметров, поэтому порядок событий важнее точного числа клеток и секунд.

## Базовые параметры

| Параметр | Значение для первого playable |
| --- | --- |
| Герой 1 | Первый путник |
| Герой 2 | Новый путник |
| Силы героя | 6 в начале забега |
| Ресурсы забега | Запасы, Мудрость, Слава |
| Ресурсы аула | Запасы аула, Память рода |
| Дорога | Loop вокруг аула по `map_*` параметрам |
| Первый гарантированный дроп | Саксаул |
| Первый выбор 1 из 3 | Юрта, Камень Тамги, Звериная тропа |
| Сценарная опасность | Волчий след или Песчаная буря на втором круге |
| Тамга | Появляется на клетке смерти или почти смерти |

## Поминутный сценарий

Визуальное правило для всех строк сценария: пустых клеток нет. Свободная buildable-ячейка рисуется как базовый декор пустыни (`dune`, `stones`, `dry_grass`, `tracks`, `bones`, `cracks`) и только после постановки карты заменяется активным тайлом.

## Сценарные развилки

### Если игрок выбирает Юрту

Юрта должна дать безопасный ресурс, но не отменять риск второго круга. Сценарная опасность добавляется как дорожное событие на дальней клетке.

```text
Юрта: Запасы +2.
Песок темнеет впереди: Волчий след открыт на дороге.
```

GDD проверяет, что безопасный выбор не делает первые 10 минут бессобытийными.

### Если игрок выбирает Камень Тамги

Камень Тамги должен усилить тему памяти до первой смерти.

```text
Камень Тамги: Мудрость +2.
Камень принимает имя Арина.
```

GDD проверяет, что игрок видит "память" до Последней Тамги, но не получает сложную систему реликтов.

### Если игрок выбирает Звериную тропу

Риск должен быть прямым результатом выбора игрока.

```text
Звериная тропа: на дороге открыт Волчий след.
Волчий след: проверка Body провалена. Силы -2.
Волчий след: род получает Славу +2 при успехе или часть награды при провале.
```

GDD проверяет, что награда за риск видна даже при провале.

## Что должно проверить GDD

1. Игрок за первые 10 минут видит весь core loop, включая наследование.
2. Первый интерактив - постановка Саксаула, а не выбор из трех карт.
3. Саксаул срабатывает при будущем прохождении, а не мгновенно при клике.
4. Первый выбор 1 из 3 дает разные стратегии: Юрта, Камень Тамги, Звериная тропа.
5. Риск второго круга появляется в любом выбранном маршруте.
6. Смерть или почти смерть не обрывает playable, а создает Последнюю Тамгу.
7. Аул получает ресурсы после результата забега.
8. Новый наследник стартует без полного сброса мира.
9. Тамга прошлого героя становится видимой целью нового героя.
10. Все ключевые изменения подтверждаются короткими строками лога.
11. В логе нет длинной прозы и постоянных модалок на обычные события.
12. UI показывает причинность: карта в руке, подсвеченный слот, поставленный тайл, будущий эффект.

## Критерий готовности первых 10 минут

Сценарий готов, если внешний тестер без объяснений словами может после первого прохода сказать:

```text
Герой идет сам.
Я ставлю знаки вокруг дороги.
Знаки меняют будущий круг.
Риск может убить героя.
Аул сохраняет часть пути.
Следующий наследник может подобрать Тамгу прошлого.
```
