## Core feeling

```text
Песнь Тамги — тюркско-кочевая игра-сказка о путнике, который выходит от родового огня, идет по кругу пути, оставляет следы, встречает помощь и риск, а после смерти оставляет знак для наследника.
```

Это игра-сказка, но не арабская сказка и не generic fantasy. Сказочность идет через путь, след, род, Тамгу, костер и наследника.

## FTUE step 1 baseline

Production baseline:

```text
Песок стирает следы.
Путь ждет первого путника.

[Отправиться в путь]

Первый путник выходит из аула.
Путь ведет его сам.
```

Решение:

- Формулировку, где огонь выступает зовущим субъектом, не использовать: звучит как мутная магия.
- `У костра ждет первый путник` оставить как безопасный ясный fallback.
- `Род хранит имена` зарезервировать для смерти, Тамги, результата забега или нового наследника.
- Костер/аул = дом, род, readiness target.
- Путь = движение наружу и сказочный зов приключения.

## First playable scope

Сначала доказываем Segment A-B:

```text
аул reveal
-> игрок нажимает "Отправиться в путь"
-> первый путник выходит из аула
-> герой идет сам
-> первый ресурс
-> карта Саксаул
-> постановка Саксаула в видимый roadside_build
-> Саксаул срабатывает на будущем проходе
```

Только после этого расширяем:

```text
выбор 1 из 3
-> field_build
-> риск
-> смерть / Последняя Тамга
-> новый наследник
-> апгрейды аула
```

## World model

Карта:

```text
aul_core       -> no-build, дом/мета
road_path      -> no-build для игрока, путь героя
road_buffer    -> no-build кромка для читаемости
roadside_build -> ближние buildable клетки, прямой эффект на проход
field_build    -> дальний buildable мир, ауры/доход/синергии
```

Road events на `road_path` разрешены как системные встречи. `no-build` означает, что игрок не строит на дороге.

## Road variation vs persistent field

Решение для первого playable:

- `field_build` - постоянный слой построек внутри забега.
- Дорога может перепрокладываться между кругами.
- Дорога должна обходить поставленные игроком тайлы.
- Песчаная вуаль скрывает перепрокладку и делает ее частью фантазии мира.
- Постройки не исчезают и не теряют позицию при новом круге.

Ключевое UX-условие:

```text
поставил тайл -> тайл остался в мире -> дорога изменилась/обошла -> эффект все еще понятен
```

Если перепрокладка выглядит хаотично или игрок теряет связь с тайлами, ограничиваем силу изменения дороги.

## UI/UX baseline

Игровой экран 16:9:

```text
верх: ресурсы, день/шаг, круг, Силы, скорость
слева: chat/combat log
центр: карта, аул, дорога, battle bubble
справа: герой, кукла, статы, экипировка/Тамга/текущая схватка
снизу: рука карт / дар-пакеты
```

Лог важен и остается постоянным. Он объясняет автодвижение, удачи, провалы, бой и причинность тайлов.

## Card and tile decisions

- Карты в MVP = тайлы 1:1 из `tiles.tsv`.
- Первый guaranteed card = `saxaul / Саксаул`.
- Оазис не стартовый: он ощущается как крупная редкая помощь.
- `saxaul` ставится в `roadside_build`.
- `yurt`, `tamga_stone`, `mirage`, `storm` используют `field_build`.
- P0 risk-card = internal id `wolf_track`, player-facing name `Звериная тропа`, placement `roadside_build`.
- `Волчий след` больше не название карты игрока. Это visual marker/log text при срабатывании `wolf_track` или scripted risk.

## Card families

Карты должны масштабироваться как семьи, а не как одиночные эффекты:

| Семья | P0 | Дальше | Зачем |
| --- | --- | --- | --- |
| Помощь пути | Саксаул | Колодец, Оазис | маленькая помощь -> крупная находка |
| Стоянка рода | Юрта | Малая стоянка, Родовая стоянка | field-экономика и рост присутствия рода |
| Память | Камень Тамги | Выветренная Тамга, Родовой знак | мудрость, Тамга, наследование |
| Звериная опасность | Звериная тропа (`wolf_track`) | Стая, Охотничья тропа | риск, слава, приручение опасности |
| Пустынная опасность | Мираж, Буря | Видение, Засыпанный источник | дальние ауры, плохие и хорошие трансформации |

## Wolf guardrail

Волк допустим как след/предвестник/опасность на границе степи и пустыни, но для P0 не делаем его мифологическим существом, тотемом, духом или сакральным знаком.

Решение:

```text
internal id = wolf_track
player-facing card name = Звериная тропа
trigger/log detail = Волчий след открыт у дороги
```

Причина:

- биологически степной волк подходит для степи, полупустыни и Центральной Азии;
- культурно волк в тюркских и тюрко-монгольских традициях слишком значимый образ, чтобы использовать его как случайного монстра;
- `Звериная тропа` звучит как место риска, которое игрок может поставить;
- `Волчий след` звучит как проявление/маркер, который игра открывает на дороге.
