# 06. Бриф для Claude

## Что реализовать первым

Актуальный короткий контракт GDD: `gamedesign/docs/28_current_source_of_truth.md`. Если старые GDD-заметки конфликтуют с ним, приоритет у `28_current_source_of_truth.md`.

1. Аул в центре.
2. Дорога-кольцо вокруг аула.
3. Зоны карты: дорога, road buffer/no-build, ближний roadside build, дальний field build.
4. Автодвижение героя по дороге.
5. Чтение баланса из `games/turkic-jam-2026/config`.
6. Наследники из `heirs.tsv`.
7. Тайлы из `tiles.tsv`.
8. Силы, Запасы, Мудрость, Слава.
9. Смерть героя.
10. Последняя Тамга на месте смерти.
11. Новый наследник после смерти.
12. Победа после 10 кругов.

Текущий порядок реализации FTUE:

1. Сначала сделать must-pass Segment A-B: выход из аула, автодвижение, первый ресурс, Саксаул, placement, отложенный эффект.
2. Затем Segment C: выбор 1 из 3 и разные placement-зоны.
3. Затем Segment D: риск, Тамга, результат, новый наследник.

Пока Segment A-B не читается без объяснений, не расширять C-D.

Первый опыт:

1. Темный экран.
2. Короткий текст интро.
3. Появляется пустыня.
4. Появляется аул и костер.
5. От костра выходит первый путник.
6. Путник сам встает на дорогу и начинает движение.

Текущий текст Step 1:

```text
Песок стирает следы.
Путь ждет первого путника.
Отправиться в путь.
Первый путник выходит из аула.
Путь ведет его сам.
```

Модель событий: обычные клетки срабатывают автоматически. Не спрашивать игрока на каждой клетке. Пауза и выбор нужны только для карты, размещения тайла, конца круга, смерти, реликта и редкого крупного события.

## Первый playable-test

Проверка кора должна быть маленькой:

```text
1-2 круга
-> герой находит карту
-> игрок ставит карту в пустыню
-> тайл помогает или повышает риск
-> герой умирает
-> аул получает ресурсы
-> новый герой выходит снова
-> новый герой может подобрать Последнюю Тамгу
```

Acceptance checklist:

1. Герой сам идет по кольцу.
2. На дороге герой получает ресурс.
3. Герой получает карту `Саксаул`.
4. Игрок ставит `Саксаул` в подсвеченную buildable-ячейку за road buffer.
5. `Саксаул` срабатывает на будущем проходе.
6. В конце круга игрок получает выбор 1 из 3 карт.
7. Второй круг дает первый риск.
8. При падении Сил до 0 появляется Последняя Тамга.
9. Часть ресурсов уходит в аул.
10. Новый наследник стартует из аула.
11. Новый наследник может подобрать Последнюю Тамгу прошлого героя.

Если эти пункты работают, core MVP доказан.

## Главная визуальная проверка

Если смотреть на игру без текста, должно быть понятно:

```text
аул -> дорога вокруг аула -> road buffer/no-build -> большой field пустыни
```

Если это не читается, игра визуально не попала в концепт.

## Главное игровое правило

Игрок не двигает героя. Игрок занимает ячейки пустыни: ближние `roadside` для прямого влияния на проход и дальние `field` для аур, синергий и дохода за круг.

## Не реализовывать сейчас

- сложную экономику;
- свободное строительство дороги;
- много биомов;
- отдельную боевую сцену;
- длинные диалоги;
- procedural generation.

## Приоритет резки

Если времени мало:

1. Убрать реликт.
2. Убрать апгрейды аула.
3. Убрать синергии.
4. Уменьшить победу с 10 кругов до 5.

Нельзя резать:

- аул в центре;
- кольцевую дорогу;
- пустынные ячейки;
- автодвижение;
- Последнюю Тамгу.
