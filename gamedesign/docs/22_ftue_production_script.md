# 22. FTUE production script

Цель: сделать FTUE настолько конкретным, чтобы по этому документу можно было реализовать первый playable без дополнительных устных объяснений.

Этот документ является главным рабочим сценарием FTUE. Если он конфликтует с более старыми FTUE-заметками, приоритет у этого документа.

## Главный принцип

Игрок должен понять core loop через действие, а не через лекцию:

```text
герой выходит из аула
-> герой сам идет по дороге
-> мир дает ресурс
-> герой находит карту Саксаул
-> игрок ставит Саксаул в roadside
-> Саксаул срабатывает позже
-> круг завершается у аула
-> игрок выбирает 1 из 3
-> второй круг дает риск
-> смерть/почти смерть создает Последнюю Тамгу
-> новый наследник подбирает Тамгу
```

## Что игрок не должен делать в FTUE

- Не управлять героем WASD/стрелками/кликами по дороге.
- Не выбирать на каждой клетке.
- Не ставить первый тайл в `road_path` или `road_buffer`.
- Не открывать справочник правил.
- Не разбираться с полной прокачкой аула.
- Не видеть Оазис как первую обучающую карту.

## Что игрок должен сделать сам

1. Поставить первый Саксаул.
2. Выбрать одну карту после первого круга.
3. Поставить выбранную карту в подсвеченную зону.
4. Нажать "Новый наследник" после результата забега.

Все остальное в первые 10 минут может быть автоматическим или scripted.

## Постоянная раскладка UI

| Зона | Что показывает | В FTUE |
| --- | --- | --- |
| Центр | карта, аул, дорога, пустыня | всегда главный фокус |
| Верх | круг, день/шаг, ресурсы забега, ресурсы аула | видим после появления карты |
| Низ | рука карт | активна только при карте/выборе |
| Слева | чат/боевой лог | короткие строки, без модалок |
| Справа | герой, Силы, статы, экипировка/пустые слоты | видим после выхода героя |

Пауза используется только для решения. Обычный ресурс, обычный урон, обычная награда и срабатывание Саксаула не ставят паузу.

## Визуальные зоны карты

| Зона | Можно строить | Как объясняется игроку |
| --- | --- | --- |
| `aul_core` | нет | дом, старт, возврат, мета-прогресс |
| `road_path` | нет | путь героя |
| `road_buffer` | нет | кромка пути, нужна для читаемости дороги |
| `roadside_build` | да | ближние тайлы, влияют на проход |
| `field_build` | да | дальняя пустыня, ауры, доход, синергии |

Свободные `roadside_build` и `field_build` не должны выглядеть пустыми. У каждой такой клетки есть `base_decor_id`.

| Поле | Значение |
| --- | --- |
| Trigger | герой входит в `linked_road_cell` |
| Camera | без паузы; акцент на Саксаул и героя |
| UI | HUD Сил и Запасов подсвечивается |
| Player input | нет |
| Animation | линия связи вспыхивает, куст качается, над героем pop-up `Силы +1`, рядом `Запасы +1` |
| Text/log | `Саксаул: путник находит тень и хворост. Силы +1. Запасы +1.` |

Это самый важный момент FTUE. Игрок должен увидеть причинность:

```text
поставил карту
-> она стала тайлом
-> тайл связан с будущей клеткой
-> герой дошел туда
-> эффект сработал
```

| Trigger | новый герой доходит до клетки с `last_tamga` |

| UI | HUD Мудрости/Славы подсвечивается |
| Player input | нет |
| Animation | Тамга вспыхивает, поднимается с песка, исчезает в HUD/панели памяти |
| Text/log | `Путник поднимает Тамгу прошлого. Мудрость +1, Слава +1.` |
| Data mutation | `run_wisdom += 1`, `run_glory += 1`, remove `last_tamga` |
| Exit | Тамга исчезла, игрок видел полный core loop |

Это финальная точка FTUE MVP.

## Acceptance checklist

FTUE готов, если тестер без устных объяснений может сказать:

1. Герой вышел из аула, а не просто появился на дороге.
2. Герой идет сам.
3. Игрок влияет через карты и тайлы.
4. Первый Саксаул поставлен в `roadside`, не в дорогу и не в buffer.
5. Саксаул сработал позже, когда герой дошел до связанной клетки.
6. Первый круг вернул героя к аулу.
7. Первый выбор из 3 понятен по ролям: безопасность, память, риск.
8. `field` и `roadside` визуально отличаются.
9. `road_buffer` понятно запрещен для строительства.
10. Второй круг показал риск.
11. Смерть или почти смерть создала Последнюю Тамгу.
12. Результат забега сохранил часть ресурсов в аул.
13. Новый наследник вышел из аула.
14. Новый наследник подобрал Тамгу прошлого.

## Что можно резать без потери core

- Озвучку.
- Сложную анимацию песка.
- Несколько вариантов первого ресурса.
- Полный экран результата с красивой статистикой.
- Сложные реликты и экипировку.

## Что нельзя резать

- Выход героя из аула.
- Автодвижение.
- Первый Саксаул как безопасная карта.
- Ручную постановку Саксаула игроком.
- Отложенное срабатывание Саксаула.
- Различие `roadside`, `field`, `road_buffer`.
- Первый риск второго круга.
- Последнюю Тамгу.
- Нового наследника.
