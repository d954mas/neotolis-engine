# 01. Карта и пространство

## Базовая структура

Карта состоит из трех слоев:

| Слой | Что это | Игрок меняет? |
| --- | --- | --- |
| Родовой аул / стойбище | Центр карты и постоянная база рода. | Да, через апгрейды. |
| Дорога | Кольцевой путь вокруг аула. По нему идет герой. | Нет, игрок не строит форму пути. |
| Пустыня | Большой скроллящийся мир вокруг дорожного коридора, куда ставятся тайлы. | Да, это главный build layer. |

## Термин центра

Игроку не говорим "центральный хаб-клетка".

Художественно это **родовой аул** или **стойбище рода**: несколько юрт, костер, старшие, память рода, место выхода наследника на путь и точка возвращения после круга.

Технически это можно называть `home_core` или `camp_core`, но в тексте и UI лучше:

```text
Стойбище рода
Родовой аул
Аул
```

Важно: "аул" - стартовая форма. В мета-прогрессии он может вырасти в укрепленный аул, город и столицу.

## Почему дорога кольцевая

Для джема дорога должна оставаться кольцом вокруг аула. Это упрощает:

- движение героя;
- читаемость карты;
- баланс круга;
- UI;
- объяснение игроку.

Игрок не строит сам путь. Он **занимает ячейки пустыни вокруг дорожного коридора и в дальнем поле**.

## Вариативность дороги

Решение после ревью Code и пользователя:

- дорога остается кольцом;
- игрок не меняет форму дороги;
- `field_build` является постоянным слоем построек внутри забега;
- дорога может перепрокладываться между кругами;
- новая дорога обходит поставленные игроком тайлы;
- песчаная вуаль скрывает перепрокладку;
- поставленные тайлы не исчезают и не теряют позицию;
- дорога строится на квадратной сетке и читается ближе к Loop Hero.

Текущие ключи из `balance.ini`:

```text
map_zone_cols = 6
map_zone_rows = 6
map_aul_w = 2
map_aul_h = 2
map_bends_base = 4
map_bends_per_circle = 1
map_bends_jitter = 2
```

Смысл:

```text
зона карты задает поле для loop;
аул занимает центр;
изгибы делают дорогу менее прямой и удлиняют круг;
каждый круг может получить другой валидный loop;
loop должен обходить постоянные постройки игрока;
круг внутри одного забега не должен обнулять или инвалидировать тайлы игрока.
```

UX-ограничение:

```text
поставленный тайл -> дорога изменилась -> игрок все еще понимает, как тайл влияет на путь
```

`path_cells`, `path_cells_growth`, `path_cells_jitter` устарели и больше не являются источником баланса.

## MVP-сетка

Рабочая модель:

- квадратная сетка в стиле Loop Hero;
- родовой аул/стойбище 2x2 в центре;
- дорога замкнуто огибает аул и занимает центральную часть карты;
- вокруг дороги есть reserved/no-build коридор под читаемость, анимации героя, battle bubble и возможную генерацию изгибов;
- за reserved-коридором начинается build layer пустыни;
- мир больше первого экрана и поддерживает скролл/камеру;
- у тайлов есть разные placement-режимы: не все должны стоять рядом с дорогой, чтобы действовать;
- внутренняя область кольца занята аулом и тоже является no-build.

## Зоны карты

| Зона | Можно строить? | Что там происходит | Визуальный ограничитель |
| --- | --- | --- | --- |
| `aul_core` | Нет | Стойбище рода, костер, выход героя, апгрейды аула. | Юрты, костер, утоптанная земля, теплый свет. |
| `road_path` | Нет | Герой идет по дороге, срабатывают road events. | Плотная дорога, колеи, дорожная пыль. |
| `road_buffer` | Нет | Запас вокруг дороги для читаемости, battle bubble, будущих изгибов дороги. | Каменная кромка, низкая насыпь, утоптанный песок, маленькие вешки. |
| `roadside_build` | Да | Ближние тайлы, которые напрямую влияют на ближайшие дорожные клетки. | Подсвечиваемые слоты за кромкой дороги. |
| `field_build` | Да | Дальние тайлы большого мира: ауры, синергии, доход за круг, глобальный риск. | Обычная живая пустыня с декором. |

Ключевое правило: `road_buffer` нужен не как пустота, а как читаемый запрет строительства. Игрок должен визуально понимать: “здесь место пути, тут строить нельзя”. Это можно показать низкой каменной каймой, утоптанной полосой, колышками, следами повозок или более плотным песком.

## Большой мир и камера

Первый экран показывает аул, часть дороги и несколько ближайших тайлов. Но вся карта не обязана помещаться в 16:9.

Цель:

- камера может двигаться по пустыне;
- вокруг центрального дорожного коридора есть много buildable-клеток;
- дальние тайлы дают стратегию не только через “стоять рядом с дорогой”;
- рост аула и новые круги открывают/делают полезными дальние зоны.

Для MVP камера может быть простой: pan, zoom, кнопка возврата к герою/аулу. Но GDD считает большой скроллящийся мир целевым направлением.

## Правило заполнения клеток

Пустых клеток на уровне быть не должно.

Это важно для ощущения живого пути: игрок должен видеть не абстрактную сетку, а пустыню, где каждая ячейка уже что-то значит визуально. Реф по ощущению - Capybara Go: экран постоянно дает мелкие сигналы, находки, следы, всплывающие числа и понятный лог.

Свободная buildable-ячейка не является пустой. До постановки карты она рисуется как базовый декор:

| decor_id | Как выглядит | Игровой смысл |
| --- | --- | --- |
| `dune` | Низкий бархан, песчаный гребень. | Спокойная клетка, можно занять картой. |
| `stones` | Несколько камней, сухая земля. | Спокойная клетка, можно занять картой. |
| `dry_grass` | Пучки сухой травы/кустарника. | Спокойная клетка, можно занять картой. |
| `tracks` | Старые следы в песке. | Намек на путь/живой мир, можно занять картой. |
| `bones` | Маленькие кости или обломки. | Тревожный декор, но не активная опасность. |
| `cracks` | Трещины, выжженный песок. | Визуальное разнообразие, можно занять картой. |

Техническая модель:

```text
cell.base_decor_id = dune / stones / dry_grass / tracks / bones / cracks
cell.tile_id = none / oasis / yurt / tamga_stone / wolf_track / ...
```

Если `tile_id = none`, клетка все равно рисует `base_decor_id` и может быть подсвечена как доступная для карты. Если игрок ставит карту, активный тайл визуально заменяет или перекрывает базовый декор.

Целевой образ:

```text
        F F F F F F F
      F B B B B B B F
      F B R R R R B F
      F B R A A R B F
      F B R A A R B F
      F B R R R R B F
      F B B B B B B F
        F F F F F F F
```

Где:

- `A` - аул;
- `R` - дорога;
- `B` - road buffer / no-build кромка;
- `F` - field/roadside buildable пустыня.

## Правило размещения

Игрок ставит карты в пустынные ячейки, но не все карты обязаны стоять рядом с дорогой.

Placement:

| Placement | Используем в MVP | Правило |
| --- | --- | --- |
| `road` | Только scripted/debug events | Клетка дороги, срабатывает при входе героя. |
| `roadside` | Да | Ближняя buildable-ячейка за road buffer. Влияет на ближайшую дорожную клетку при проходе героя. |
| `field` | Да, как направление дизайна; технически можно вводить после direct-roadside | Дальняя пустыня. Может работать через радиус, соседство, доход за круг, глобальный модификатор или синергию. Не требует соседства с дорогой. |

Примеры:

| Тайп | Placement | Как действует |
| --- | --- | --- |
| `saxaul` / Саксаул | `roadside` | Маленькая помощь на ближайшем проходе: Запасы +1, Силы +1. Хороший первый обучающий тайл. |
| `oasis` / Оазис | `roadside` или редкий `field`-landmark | Сильная помощь. Не должен быть первой картой, потому что ощущается как крупная находка. |
| `yurt` / Юрта | `field` | Стоянка/поддержка: доход за круг, усиление соседних тайлов, подготовка синергий. |
| `tamga_stone` / Камень Тамги | `field` | Память/мудрость, ауры, синергии с опасностями и юртами. |
| `wolf_track` / Звериная тропа | `roadside` | Риск рядом с маршрутом, проверка при проходе. Волчий след - визуальный маркер срабатывания. |
| `mirage` / Мираж | `field` | Дальняя опасность/аура, Mind-риск или искажение наград в зоне. |
| `storm` / Песчаная буря | `field` | Зональная угроза, может влиять на несколько клеток/тайлов. |

Каждый поставленный тайл:

- для `roadside`: дает эффект при прохождении ближайшей дорожной клетки;
- для `field`: действует через радиус, соседство, доход за круг, глобальный риск или синергию;
- может усиливаться соседними пустынными тайлами;
- может стать реликтом после смерти;
- может быть стертым после смерти героя.

## Что видно игроку

Игрок должен сразу понимать:

- где аул;
- где герой;
- какая клетка дороги следующая;
- какие пустынные ячейки заняты;
- где есть Последняя Тамга;
- какой тайл опасный, а какой безопасный.

## Что не делать

Не делать на MVP:

- свободное рисование пути;
- сложные правила соседства;
- скрытые эффекты тайлов;
- процедурную пустыню, которая спорит с читабельностью дороги.
