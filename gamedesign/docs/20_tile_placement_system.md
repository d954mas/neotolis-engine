# 20. Tile placement system

Цель: зафиксировать, как игрок ставит тайлы в большой пустынный мир, какие зоны существуют и почему не все тайлы должны стоять рядом с дорогой.

## Короткое решение

```text
road_path      -> no-build, герой идет здесь
road_buffer    -> no-build, кромка дороги и место под читаемость/анимации
roadside_build -> build, прямое влияние на ближайший проход героя
field_build    -> build, дальний скроллящийся мир
```

Первый обучающий тайл:

```text
saxaul / Саксаул
placement = roadside
effect = Силы +1, Запасы +1
```

Оазис не первая карта. Он сильнее, ценнее и должен ощущаться как крупная находка.

## Зоны

| Зона | Build | Назначение | Примеры визуала |
| --- | --- | --- | --- |
| `aul_core` | Нет | Стойбище рода, костер, выход героя, апгрейды. | Юрты, костер, утоптанная земля. |
| `road_path` | Нет | Путь героя, road events, текущая клетка. | Колеи, плотная дорога, пыль. |
| `road_buffer` | Нет | Запас вокруг дороги, battle bubble, читаемость, будущая генерация изгибов. | Каменная кромка, колышки, утоптанный песок. |
| `roadside_build` | Да | Ближние тайлы, работающие на ближайшую дорожную клетку. | Подсвечиваемые декор-клетки за кромкой дороги. |
| `field_build` | Да | Дальние тайлы большого мира. | Живая пустыня с декором, скролл камеры. |

`road_buffer` нельзя оставлять визуально пустым. Он должен объяснять запрет строительства: это кромка пути, не место для тайла.

## Placement

| Placement | Где ставится | Как действует |
| --- | --- | --- |
| `road` | На road-клетке | Только scripted/debug events. Игрок обычно не ставит. |
| `roadside` | В `roadside_build` за road buffer | Срабатывает при проходе ближайшей/связанной road-клетки. |
| `field` | В `field_build` | Работает через радиус, соседство, доход за круг, ауру, глобальный риск или синергию. |

## Первые тайлы

| ID | Placement | Роль | Эффект/смысл |
| --- | --- | --- | --- |
| `saxaul` | `roadside` | Малая помощь | Силы +1, Запасы +1 на связанном проходе. |
| `oasis` | `roadside` или редкий `field` landmark | Сильная помощь | Больше восстановления и Запасов, не стартовый тайл. |
| `yurt` | `field` | Экономика/стоянка | Доход за круг, синергии с Саксаулом/Оазисом/Тамгой. |
| `tamga_stone` | `field` | Память | Мудрость, ауры памяти, синергии с наследием. |
| `wolf_track` | `roadside` | Риск | Player-facing name: Звериная тропа. Body check на маршруте, Слава за риск. На дороге визуально проявляется Волчий след. |
| `mirage` | `field` | Mind-риск | Дальняя аура, искажение наград/проверок. |
| `storm` | `field` | Spirit-риск | Зональная угроза, сильная награда. |

## Подсветка при выборе карты

Когда игрок выбирает карту:

1. Игра читает `placement`.
2. Подсвечивает только допустимые buildable-клетки.
3. `road_path`, `road_buffer`, `aul_core` не подсвечиваются.
4. Неверный клик не ставит карту.
5. UI должен коротко объяснить причину:

```text
Здесь проходит дорога.
Здесь кромка пути: строить нельзя.
Эта карта ставится дальше от дороги.
Эта карта должна стоять у дороги.
```

## Первый обучающий сценарий

```text
герой проходит 2-3 road-клетки
-> получает Саксаул
-> игра ставит паузу
-> подсвечивает один roadside_build слот за road_buffer
-> игрок ставит Саксаул
-> герой проходит связанную road-клетку
-> Саксаул: Силы +1, Запасы +1
```

Это учит причинности:

```text
карта в руке -> buildable-клетка -> тайл на поле -> будущий проход героя
```

## Почему field нужен рано

Даже если первый клик `roadside`, игрок должен видеть, что мир больше дороги.

Field нужен для:

- скролла камеры;
- ощущения большой пустыни;
- будущей прокачки аула и открытия дальних зон;
- тайлов, которые не обязаны касаться дороги;
- синергий формы и радиуса;
- роста сложности без перегруза дорожного кольца.

## Acceptance для Code

1. На карте есть no-build `road_buffer`.
2. Buildable-клетки имеют `base_decor_id`.
3. `saxaul` можно поставить только в допустимый `roadside_build`.
4. `yurt`, `tamga_stone`, `mirage`, `storm` подсвечивают `field_build`.
5. Неверный placement не проходит.
6. Поставленный тайл остается на карте и визуально заменяет/перекрывает базовый декор.
7. Камера/карта допускает мир больше первого экрана.
