# 15. Первый контент карт

Цель: подготовить набор карт, который можно использовать сразу после playable core.

Для MVP карты временно равны тайлам из `tiles.tsv`. Это нормально: игрок получает карту, ставит ее в допустимую buildable-клетку, а тайл начинает работать по своему `placement`.

Важно: не все карты должны стоять рядом с дорогой. Ближние `roadside`-тайлы меняют конкретный будущий проход героя, а дальние `field`-тайлы работают через радиус, соседство, доход за круг, ауры, глобальный риск или синергии.

Первая обучающая карта - **Саксаул**, а не Оазис. Оазис в пустыне ощущается как крупная редкая находка, поэтому он должен быть сильнее и появляться позже.

## Роли карт

| Роль | Что делает | Почему нужна |
| --- | --- | --- |
| Помощь | Восстановление и безопасный ресурс | Игрок должен увидеть, что карта помогает. |
| Память | Мудрость, Тамги, наследие | Отличает игру от Loop Hero. |
| Риск | Проверка и высокая награда | Создает решение, а не декор. |
| Контроль риска | Снижает опасность рядом | Дает игроку чувство планирования. |
| Синергия | Меняет смысл соседних тайлов | Делает пустыню живой. |

## Первый набор выбора после круга

После первого круга:

```text
Юрта
Камень Тамги
Волчий след
```

Почему:

- `Юрта` - безопасная экономика;
- `Камень Тамги` - память и тема игры;
- `Волчий след` - первый риск.

Это хороший первый выбор: игрок выбирает не между числами, а между стратегиями.

## Второй набор выбора

После второго круга:

```text
Оазис
Мираж
Песчаная буря
```

Почему:

- `Оазис` - восстановиться после риска;
- `Мираж` - риск Mind;
- `Песчаная буря` - тяжелый Spirit-риск.

## Первые синергии

| Условие | Новый смысл | Что показать игроку |
| --- | --- | --- |
| Саксаул рядом с Юртой | Малая стоянка | Даже слабый куст может стать точкой отдыха, если рядом есть люди. |
| Оазис рядом с Юртой | Стоянка | Аул как культура начинает занимать пустыню. |
| Камень Тамги рядом с Юртой | Родовой знак | Память становится частью стоянки. |
| Волчий след рядом с Сторожевой вышкой | Охотничья тропа | Опасность можно приручить. |
| Мираж рядом с Камнем Тамги | Видение | Риск дает знание. |
| Буря накрывает Оазис | Засыпанный источник | Сильная помощь может стать опасной наградой. |
| Два Волчьих следа рядом | Стая | Жадность игрока создает опасность. |

## Что нужно от Code позже

Когда playable core работает, можно заводить `cards.tsv`:

```text
id | name | tile_id | placement | rarity | drop_weight | first_seen_circle | desc
```

До этого достаточно `tiles.tsv` 1:1.
