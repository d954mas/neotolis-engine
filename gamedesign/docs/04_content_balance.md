# 04. Контент и баланс

## Источник чисел

Числа баланса уже вынесены в конфиги:

```text
games/turkic-jam-2026/config/balance.ini
games/turkic-jam-2026/config/heirs.tsv
games/turkic-jam-2026/config/tiles.tsv
```

GDD не должен спорить с этими файлами. Если нужно менять числа, менять их там.

## MVP-контент

Обязательный минимум:

- 12 клеток дороги;
- 10 кругов для победы;
- 3 наследника;
- 7 тайлов;
- 4 ресурса;
- Последняя Тамга;
- 1 реликт;
- смерть и новый наследник;
- экран победы.

## Тайлы MVP

Текущие тайлы из `tiles.tsv`:

| ID | Имя | Роль |
| --- | --- | --- |
| `saxaul` | Саксаул | Первый обучающий тайл. Малая помощь: Запасы +1, Силы +1. |
| `oasis` | Оазис | Более сильный безопасный ресурс и восстановление Сил. Не первая карта. |
| `yurt` | Юрта | Field-поддержка, Запасы, синергии и стоянки. |
| `tamga_stone` | Камень Тамги | Field-память, Мудрость, синергии. |
| `wolf_track` | Звериная тропа | Roadside-риск, Body check, Слава. Волчий след используется как визуальный/логовый маркер. |
| `mirage` | Мираж | Field-опасность/аура, Mind check, Мудрость и Слава. |
| `storm` | Песчаная буря | Field-зона риска, Spirit check, высокая Слава. |

Этого достаточно для первого полноценного цикла.

## Синергии

Синергии пока не в конфиге. Когда программист добавит таблицу, ожидаемое имя:

```text
games/turkic-jam-2026/config/synergies.tsv
```

Дизайн MVP:

| Синергия | Смысл |
| --- | --- |
| Саксаул + Юрта | Малая стоянка. Запасы, слабое восстановление. |
| Оазис + Юрта | Сильная стоянка. Больше Запасов и восстановления. |
| Камень Тамги + Буря | Песнь ветра. Буря мягче, но дает Мудрость. |
| Звериная тропа + Звериная тропа | Стая. Опаснее, но больше Славы. |
| Звериная тропа + Сторожевая вышка | Охотничья тропа. Опасность можно приручить. |

## Испытания круга

Пока не в конфиге. Когда появятся, ожидаемое имя:

```text
games/turkic-jam-2026/config/trials.tsv
```

MVP может временно использовать повторяющееся испытание на конце круга, но лучше иметь 10 названных испытаний.

## Что резать первым

Если не хватает времени:

1. Реликт.
2. Апгрейды аула.
3. Синергии.
4. Часть испытаний круга.

Что нельзя резать:

- аул в центре;
- дорога вокруг аула;
- ближние roadside-ячейки и дальние field-ячейки пустыни;
- автоматическое движение;
- Последняя Тамга.
