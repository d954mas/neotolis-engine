# 02. Основной цикл

## Цикл игрока

1. Выбрать наследника.
2. Запустить героя на дорогу.
3. Смотреть, как герой проходит клетки.
4. Получать ресурсы, риски и события от тайлов.
5. После круга выбрать улучшение героя.
6. Выбрать карту и занять новую пустынную ячейку.
7. Пройти следующий круг.
8. Умереть или дойти до 10-го круга.

## Цикл героя

Герой:

- стартует из аула;
- идет по дорожным клеткам по порядку;
- сам активирует события;
- теряет или восстанавливает Силы;
- возвращается в аул после полного круга;
- умирает, если Силы падают до 0.

## Цель одного забега

Один забег = жизнь одного наследника.

Победа забега:

- герой прошел 10 кругов подряд;
- герой вернулся в аул после финального круга.

Смерть:

- забег заканчивается;
- появляется Последняя Тамга;
- игрок выбирает один реликт;
- новый наследник начинает с первого круга.

## Ритм круга

Круг должен быть коротким. Игрок не должен ждать слишком долго.

Текущий балансный источник:

- `map_zone_cols / map_zone_rows`
- `map_aul_w / map_aul_h`
- `map_bends_base / map_bends_per_circle / map_bends_jitter`
- `laps_to_win = 10`
- `move_seconds_per_cell = 1.5`

Длина loop теперь выводится из геометрии карты, а не из `path_cells`.

Эти числа находятся в:

```text
games/turkic-jam-2026/config/balance.ini
```

## Между кругами

После успешного круга:

1. Герой получает личное улучшение.
2. Игрок получает выбор карты.
3. Игрок ставит карту в пустыню или улучшает аул.
4. Следующий круг становится опаснее.

## Почему это должно работать

Игрок не управляет моментом. Он управляет подготовкой.

Напряжение рождается из вопроса:

> Я поставлю полезный тайл сейчас, но выдержит ли наследник последствия на следующих кругах?
