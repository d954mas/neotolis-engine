## Acceptance Criteria

### UI

1. Every 9-slice source has clean transparent corners where appropriate.
2. Corners are decorated enough for Turkic identity but not too noisy.
3. Centers remain clean and stretchable.
4. Cards read as spendable playable cards, not inventory plaques.
5. No game title, no full carpet wallpaper, no heavy gold fantasy UI.

### World

1. Assets read at `64x64` gameplay scale after downsample.
2. `road_path` and `road_buffer` are visually distinct.
3. `road_buffer` reads as no-build but not wall/fence.
4. Empty decor stays quieter than active tile sprites.
5. `tile_saxaul_01` is low/wide brushwood, not a tall tree and not oasis.
6. Transparent sprites contain no baked sand background.

## Generation Prompts

These prompts define the visual intent for future regenerated/painted versions. Batch A files in this folder are exact-size production drafts.

### UI 9-Slice Prompt

```text
Create reusable nine-slice UI assets for a 2D roguelite loop-builder with Turkic nomadic identity, based on the approved gameplay UI reference. Assets: dark felt panel, light felt panel, playable parchment card face, selected card face with green/teal edge, equipment slot, HUD chip, compact tooltip. Style: flat readable game UI, restrained woven geometric trim, tamga accents, felt/leather/wood/bone materials, warm ochre edges, teal memory accent, muted clan red details. Centers must be clean for stretching, decoration mostly in corners and borders. No text, no game title, no full carpet wallpaper, no ornate gold fantasy, no Arabic palace, no genie lamp, no flying carpet, no bazaar, no photorealism, no watermark.
```

Negative:

```text
game title, full screen mockup, heavy leather card faces, inventory plaque cards, ornate gold frame, full carpet wallpaper, arabian palace, genie lamp, flying carpet, bazaar, photorealistic texture noise, text labels, watermark
```

### World P0 Prompt

```text
Create exact top-down 2D game sprites for a Turkic nomadic desert roguelite loop-builder. Warm ochre sand, packed dirt road, no-build road buffer with sparse low stones and packed sand, quiet base decor cells, central aul objects, low wide saxaul brushwood, tiny wayfarer hero. Flat readable jam art style, clean silhouettes, low detail, transparent active sprites over ground. Road and buffer must be distinct. Saxaul must be low and wide, not a tree. No empty blank beige cells, no palm oasis, no arabian palace, no genie lamp, no flying carpet, no bazaar, no photorealism, no watermark.
```
