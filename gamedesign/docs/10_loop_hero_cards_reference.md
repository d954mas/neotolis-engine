# 10. Loop Hero: карты, эффекты и синергии

Дата: 2026-06-05

Цель документа: понять, как устроены карты в Loop Hero, чтобы сделать похожую по функции, но тематически свою систему для "Песни Тамги".

## Короткий вывод

В Loop Hero карты - это не "заклинания на один ход". Это способ строить мир, который герой потом проходит автоматически.

Карты работают несколькими способами:

1. **Постоянный модификатор** - стоят на карте и всегда дают эффект.
2. **Тайл-событие** - герой входит на клетку и получает бой, лечение, награду или риск.
3. **Спавнер** - тайл периодически создает врагов или события.
4. **Соседство** - эффект зависит от того, что стоит рядом.
5. **Трансформация** - несколько тайлов превращаются в новый тайл.
6. **Удаление/активация** - редкая карта меняет уже построенную карту.

Для "Песни Тамги" нам нужен такой же принцип:

```text
карта = след в пустыне,
след меняет будущий проход путника.
```

## Типы карт в Loop Hero

| Тип | Где ставится | Функция |
| --- | --- | --- |
| Road | На дорогу | Меняет клетку, по которой герой идет. Часто дает бой, лечение или событие. |
| Roadside | Рядом с дорогой | Влияет на соседние дорожные клетки, часто спавнит врагов или меняет условия боя. |
| Landscape | Не на дорогу и не рядом с дорогой | Дает постоянные статовые эффекты или усиливает другие ландшафты. |
| Special | Особое размещение/эффект | Работает как отдельный инструмент: удалить тайл, усилить зону, создать казну. |
| Golden | Один раз за экспедицию | Сильный уникальный модификатор забега. |

Главный урок: **тип карты задает не тему, а место и способ действия**.

Для нас:

| Loop Hero | Песнь Тамги |
| --- | --- |
| Road | Клетки дороги, по которым идет путник |
| Roadside | Пустыня рядом с дорогой |
| Landscape | Дальняя пустыня / внешний слой |
| Special | Тамга, реликт, песнь, очищение |
| Golden | Священный знак рода / редкая память |

## Примеры карт Loop Hero по функциям

### Постоянные ландшафтные бонусы

Эти карты стоят на карте и дают постоянный фоновой эффект.

| Карта | Принцип |
| --- | --- |
| Rock / Mountain | Увеличивают здоровье героя. |
| Meadow | Лечит героя по дневному циклу. |
| Forest / Thicket | Ускоряют атаки героя. |
| Desert / Sand Dunes | Снижают здоровье существ, меняя баланс риска. |
| Suburbs | Ускоряют набор опыта. |

Важно: эти карты не требуют решения каждый раз. Игрок поставил их один раз, и мир стал другим.

### Клетки дороги

Эти карты меняют то, что герой встречает ногами.

| Карта | Принцип |
| --- | --- |
| Cemetery | Регулярно создает боевую угрозу на дороге. |
| Grove | Создает врагов, но дает ценные ресурсы. |
| Village | Лечит/дает квестовую структуру, но может быть изменена соседством. |
| Swamp | Меняет правило лечения и делает путь опаснее. |
| Ruins | Дает награды, но создает угрозу. |

Важно: дорога - это "что герой проживает телом".

### Карты рядом с дорогой

Эти карты обычно влияют на соседние дорожные клетки.

| Карта | Принцип |
| --- | --- |
| Spider Cocoon | Спавнит врагов рядом с дорогой. |
| Vampire Mansion | Добавляет врага в бои рядом, но открывает сильные трансформации. |
| Battlefield | Дает сундук/лут, но пересечения создают Blood Path. |
| Blood Grove | Добивает врагов при условии соседства с лесом/рощей. |
| Road Lantern | Снижает плотность врагов на соседних клетках. |
| Chrono Crystals | Усиливает эффекты, завязанные на дневной цикл. |

Важно: roadside-карты - хороший формат для первого обучения, потому что они прямо связывают карту с будущим проходом героя.

Но наша целевая карта больше, чем кольцо дороги: `field`-тайлы нужны для большого скроллящегося мира, дальних аур, синергий и дохода за круг.

## Как работали синергии и объединения

В Loop Hero синергия - это не просто "+1 к ресурсу". Часто это **новый тайл с новым поведением**.

| Комбинация | Новый результат | Почему это хорошо |
| --- | --- | --- |
| 3x3 Rocks/Mountains | Mountain Peak | Игрок видит форму, получает большой бонус и новую угрозу. |
| Meadow рядом с любым не-Meadow тайлом | Blooming Meadow | Простая синергия соседства, легко открыть самому. |
| Village + Vampire Mansion | Ransacked Village, затем Count's Lands | Опасность превращается в долгосрочную выгоду. |
| Пересечение двух Battlefield | Blood Path | Плохая/опасная синергия от жадности игрока. |
| Treasury, окруженная 8 тайлами | Empty Treasury | Простая цель размещения: достроить вокруг. |
| Forest/Thicket под линией Storm Temple | Burned Forest | Один тип бонуса превращается в другой. |
| River рядом с Desert/Sand Dunes | Oasis | Ландшафты создают новый баланс скорости/риска. |
| Forest/Thicket рядом с Desert/Sand Dunes | Maquis | Смешение двух систем меняет врагов. |
| 5 Suburbs/Towns крестом | Town | Форма на сетке дает улучшенный тайл. |
| Blood Grove без нужного соседства | Hungry Grove | Нарушение условия превращает пользу в опасность. |

Главный урок:

```text
синергия должна быть видимой на карте,
а не спрятанной только в формуле.
```

## Как именно действовали карты: всегда или при входе?

Ответ: по-разному. Это и делает систему глубокой.

| Режим действия | Как работает | Пример из Loop Hero | Как применить нам |
| --- | --- | --- | --- |
| Постоянно | Пока тайл стоит, эффект активен | Mountain, Forest, Desert | Тамга/Камень/Стоянка дают фоновые бонусы |
| По времени | Эффект происходит раз в N дней | Meadow, spawners | Оазис копит воду, Звериная тропа создает угрозу |
| При входе героя | Герой наступает на клетку и получает событие | Village, Cemetery, Ruins | Путник проходит стоянку, бурю, след, курган |
| По соседству | Эффект зависит от рядом стоящих тайлов | Blooming Meadow, Blood Grove | Юрта рядом с Оазисом = Стоянка |
| По форме | Сетка складывается в новый объект | Mountain Peak, Town | 3 Тамги вокруг клетки = Священный знак |
| По переполнению риска | Хорошие тайлы могут создать опасность | Blood Path, Hungry Grove | Слишком много следов хищников будит стаю |
| Одноразово | Разовая активация или удаление | Oblivion | Песнь очищения убирает опасный тайл |

## Что нам брать

Брать:

- карты как главный способ действия игрока;
- разные зоны постановки;
- постоянные эффекты;
- события при прохождении героя;
- спавн опасности;
- синергии соседства;
- синергии формы;
- трансформации "риск сейчас -> выгода позже";
- плохие синергии от жадности.

Не брать в MVP:

- слишком много типов карт;
- скрытые правила без визуального намека;
- сложную экипировку как отдельную игру;
- длинный список врагов;
- несколько классов с разными карточными метами.

## Рекомендация для "Песни Тамги"

Для первого билда сделать 3 типа карт:

| Наш тип | Где ставится | Зачем |
| --- | --- | --- |
| Road event | На дорожную клетку | Прямое событие путника. |
| Desert tile | В пустыню рядом с дорогой | Главный инструмент игрока: помощь/риск/ресурсы. |
| Memory tile | Особый знак/Тамга | Наследие, смерть, аул, синергии памяти. |

Для первого клика можно начать с `roadside`, но GDD фиксирует `field` как обязательное направление карты: мир должен расти за пределы дорожной кромки.

## Ответ на вопрос

Да, в Loop Hero часть карт действовала "всегда": например ландшафтные карты меняли статы или фоновые эффекты, пока стояли на карте.

Но не все карты такие. Сила Loop Hero в смеси:

```text
постоянные бонусы
+ события при прохождении
+ спавнеры
+ соседство
+ трансформации
+ опасные последствия жадности
```

Для нас правильная модель:

```text
карта ставится в пустыню,
становится тайлом,
тайл влияет на будущие проходы,
а соседство тайлов может создать новый смысл.
```
