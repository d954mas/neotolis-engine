# 19. Claude UI mockups

Цель: дать Code не только раскладку зон, а понятные состояния экрана, чтобы UI можно было собрать без угадывания.

## Final gameplay layout

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ TOP HUD: Запасы | Мудрость | КРУГ 1/10 | День | Силы | x1/Пауза              │
├──────────────┬───────────────────────────────────────────────┬───────────────┤
│ CHAT / LOG   │ CAMERA MAP                                    │ HERO PANEL    │
│ 6-10 строк   │ аул, дорога, герой, пустыня, build-slots       │ кукла героя   │
│ автоход      │ pan / zoom / center on hero                   │ экипировка    │
│ проверки     │ battle bubble поверх клетки боя               │ статы         │
│ награды      │                                               │ текущий бой   │
├──────────────┴───────────────────────────────────────────────┴───────────────┤
│ CARD HAND: Саксаул | Юрта | Тамга | След | пусто                             │
└──────────────────────────────────────────────────────────────────────────────┘
```

Это не пошаговая игра. Герой сам идет по дороге. Игрок двигает камеру, выбирает карту тайла снизу и ставит ее в пустыню.

## Why this layout

- Карты снизу ощущаются как рука игрока, а не как editor-палитра.
- Чат слева работает как вертикальный журнал автопрохода.
- Карта остается главным объектом, а камера дает место для растущей пустыни.
- Герой справа читается как RPG-панель: кукла, статы, экипировка, текущий бой.
- Battle bubble на карте показывает место события сразу, без поиска в логе.

- если карту нельзя поставить, причина идет в лог.

Поведение:

- правая панель показывает детали текущей проверки;
- чат показывает историю результата человеческим языком.

## Mockup D: camera

```text
CENTER MAP controls:

[-] [+] [⌂]

drag / pan      — осмотреть растущую пустыню
zoom in/out     — приблизить район строительства
⌂ center        — вернуть камеру к аулу или герою
```

Камера не управляет героем. Она нужна для строительства и прокачки пустыни.
