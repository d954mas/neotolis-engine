# Песнь Тамги

Game Design Document / GDD

# 1. Обзор

Песнь Тамги — roguelite loop-builder про род кочевников, запертый в проклятом кольце пустыни. Игрок выбирает наследников, развивает аул, строит временную пустыню вокруг священного пути и пытается провести одного героя через десять кругов подряд.

| Параметр | Решение |
| --- | --- |
| Жанр | Roguelite loop-builder, idle/autonomous movement. |
| Камера | Вид сверху или изометрия. Для MVP — 2D/условная 3D сцена. |
| Сессия | Короткие забеги по 5-15 минут, в джемовой версии можно быстрее. |
| Цель | Провести одного наследника через 10 кругов. |
| Проигрыш | Нет глобального game over. Смерть заканчивает текущий забег. |

# 2. Дизайн-пиллары

Непрямое управление: герой идёт сам, игрок строит мир вокруг пути.

Поколения: каждый герой временный, род постоянный.

Смерть как память: погибший оставляет Последнюю Тамгу, которую может найти следующий герой.

Пустыня как билд забега: растёт во время жизни героя, но стирается после смерти.

Аул как мета-прогресс: улучшает наследников и открывает новые карты.

Синергии тайлов: пустыня реагирует на окружение, как в Loop Hero.

# 3. Основной игровой цикл

Игрок выбирает наследника из 3 кандидатов.

Наследник стартует из аула на Circle 1.

Герой автоматически движется по круговому пути из 12 клеток.

Каждая клетка/тайл запускает событие.

Герой получает Запасы, Мудрость, Славу, карты или теряет Силы.

В конце круга срабатывает Испытание круга.

Если герой жив и прошёл испытание, он возвращается в аул.

Игрок выбирает личное улучшение героя.

Игрок выбирает карту/улучшение для аула или пустыни.

Герой идёт на следующий круг.

Если Силы заканчиваются, герой умирает, забег заканчивается.

# 4. Структура забега

Один забег — это жизнь одного наследника. Наследник начинает с первого круга и пытается пройти до десятого. Каждый пройденный круг делает героя сильнее, а пустыню богаче и опаснее.

Круг 1: стартовый путь, низкая сложность.

Круги 2-5: появляются новые тайлы, растёт ценность ресурсов.

Круги 6-9: опасности становятся серьёзными, важны синергии и личные апгрейды.

Круг 10: финальное испытание, разрыв кольца.

# 5. Постоянное и временное

| Параметр | Решение |
| --- | --- |
| Постоянно | Аул, прокачка рода, открытые карты, ресурсы аула, Последние Тамги, некоторые реликты. |
| Временно | Текущий герой, личные апгрейды героя, построенная пустыня текущего забега, текущий номер круга. |
| После смерти | Герой и пустыня сбрасываются. Аул сохраняется. Одна карта может стать реликтом. |

# 6. Карта

Карта состоит из аула в центре и кругового пути вокруг него. Для MVP достаточно 12 клеток пути. Игрок строит окружение пути: тайлы можно считать местами рядом с дорогой, но технически они могут стоять прямо на клетках.

Путь не меняет форму.

Пустыня вокруг пути меняется через карты.

После смерти пустыня стирается.

В следующем забеге может остаться один реликт и несобранные Последние Тамги.

# 7. Ресурсы

| Параметр | Решение |
| --- | --- |
| Запасы | Вода, еда, шкуры, войлок, животные, инструменты. Тратятся на подготовку, практичные апгрейды аула и безопасные тайлы. |
| Мудрость | Знание пути, духов и смертей. Открывает карты, улучшения и новые возможности. Основная награда за Последние Тамги. |
| Слава | Имя рода. Главный глобальный прогресс и условие открытия сильных возможностей. |
| Силы | Личный ресурс героя. Провалы и опасности уменьшают Силы. При 0 герой погибает. |

# 8. Наследники

Перед началом нового забега игрок выбирает одного наследника. В MVP достаточно трёх архетипов.

| Параметр | Решение |
| --- | --- |
| Охотник | Body 3, Mind 1, Spirit 1. Хорош против зверей, волчьих следов и физической опасности. |
| Шаман | Body 1, Mind 1, Spirit 3. Хорош против духов, бурь и священных мест. |
| Сказитель | Body 1, Mind 3, Spirit 1. Хорош против миражей, руин, загадок и при сборе Последних Тамг. |

Дополнительно каждый наследник может иметь случайную черту: +1 Силы, +1 к награде за конкретный тип тайлов, +1 к сбору Мудрости и т.д. Для MVP это опционально.

# 9. Характеристики героя

| Параметр | Решение |
| --- | --- |
| Body | Физические испытания, звери, жёсткая местность, драки. |
| Mind | Миражи, руины, загадки, чтение знаков, память. |
| Spirit | Духи, бури, священные места, мистические испытания. |
| Stamina / Силы | Запас жизни/выносливости. Если падает до 0, герой погибает. |

# 10. Проверки и опасности

Опасные тайлы не требуют отдельной боевой системы. Они работают через stat check.

Пример логики: если stat >= difficulty, герой получает полную награду. Если stat < difficulty, герой теряет Силы и может получить частичную награду. Если Силы стали 0, герой погибает.

Сложность может расти от номера круга: difficulty = base + circle_modifier.

# 11. Тайлы пустыни

| Параметр | Решение |
| --- | --- |
| Оазис | Безопасный тайл. Даёт Запасы и восстанавливает Силы. |
| Юрта / Стоянка | Поддержка. Даёт Запасы и усиливает соседние тайлы. |
| Камень Тамги | Даёт Мудрость, усиливает духовные синергии. |
| Волчий след | Body check. Даёт Славу, опасен для слабых героев. |
| Мираж | Mind check. Даёт Мудрость и Славу, может отнять Силы. |
| Дух ветра | Spirit check. Даёт Мудрость или особый бонус. |
| Песчаная буря | Сложная проверка. Много Славы, высокий риск потери Сил. |
| Древние руины | Mind check. Даёт Мудрость, карты или Славу. |

# 12. Синергии пустыни

Синергии нужны, чтобы пустыня ощущалась живой и реагирующей на окружение.

Оазис + Юрта = Стоянка. Больше Запасов и/или восстановления Сил.

Камень Тамги + Дух ветра = Успокоенный дух. Ниже сложность, больше Мудрости.

Оазис + Буря = Высохший оазис. Оазис слабее, буря даёт больше Славы.

Волчий след + Юрта = Волчья стая. Сложнее проверка, выше награда.

Камень Тамги + Руины = Священные руины. Больше Мудрости и Славы.

# 13. Карты

Карты — главный способ изменения мира и аула. После полного круга игрок выбирает одну из трёх карт.

Карты пустыни: поставить новый тайл или улучшить существующий.

Карты аула: постоянные улучшения рода.

Реликтовые карты: ослабленные следы прошлого забега.

Для MVP можно не делать отдельную покупку за ресурсы: выбор карты сам является наградой. Ресурсы открывают новые карты и апгрейды.

# 14. Аул

Аул — постоянный слой прогресса. Он не должен превращаться в сложный city builder в MVP. Лучше реализовать его как набор простых постоянных апгрейдов.

| Параметр | Решение |
| --- | --- |
| Охотничий стан | Новые наследники получают +1 Body или бонус к Волчьим следам. |
| Шаманская юрта | Новые наследники получают +1 Spirit или бонус к духовным тайлам. |
| Костёр сказителей | Больше Славы за круги и Последние Тамги. |
| Хранилище | После смерти сохраняется больше Запасов. |
| Совет старейшин | Больше выбор наследников или карт. |

# 15. Последняя Тамга

Когда герой погибает, на месте смерти появляется Последняя Тамга. Это не вечный бафф, а собираемый объект. Будущий герой должен дойти до неё, чтобы получить Мудрость и немного Славы.

Рекомендуемая формула награды:

wisdom_reward = 3 + circle * 3 + floor(slot_index / 3) + danger_bonus

glory_reward = floor(wisdom_reward / 3)

circle — номер круга, где погиб герой.

slot_index — номер клетки внутри круга.

danger_bonus — +0 для обычной клетки, +2 для опасности, +5 для Хранителя/испытания круга.

Максимальное количество активных Последних Тамг можно ограничить 3. Если появляется новая сверх лимита, самая старая стирается песком или игрок выбирает, какую сохранить.

# 16. Реликты

После смерти игрок выбирает один тайл из построенной пустыни, который переживёт пески и перейдёт в следующий забег в ослабленной форме.

| Параметр | Решение |
| --- | --- |
| Оазис lvl 3 | Старый Оазис lvl 1. |
| Юрта lvl 2 | Остатки Стоянки lvl 1. |
| Камень Тамги | Выветренная Тамга. |
| Песчаная буря | След Бури. |

Для MVP оставить только 1 активный реликт. Позже апгрейд аула может позволить сохранять 2 реликта.

# 17. Завершение круга

Когда герой дошёл до аула после полного оборота, круг считается завершённым. Это не конец забега. Герой получает улучшение и идёт на следующий круг.

Аул получает 100% наград круга.

Герой получает личное улучшение: +Body, +Mind, +Spirit или +Силы.

Игрок выбирает одну из трёх карт.

Игрок ставит карту в пустыню или улучшает аул.

Circle += 1.

# 18. Испытания круга

В конце каждого круга может быть особое событие — аналог босса, но без отдельной боевой сцены. Это карточка/проверка с повышенной наградой и риском.

Круг 1: Волки на закате.

Круг 2: Высохший колодец.

Круг 3: Мираж предков.

Круг 4: Дух ветра.

Круг 5: Железные врата.

Круг 6: Чёрная буря.

Круг 7: Долина костей.

Круг 8: Камень Тамг.

Круг 9: Серый волк.

Круг 10: Последняя песнь пути.

# 19. Смерть героя

Смерть завершает текущий забег, но не игру.

Герой погибает, если Силы <= 0.

Аул получает 50% Запасов, 100% Мудрости, 50% Славы из текущего забега.

На клетке смерти появляется Последняя Тамга.

Игрок выбирает один реликт из построенных тайлов.

Пустыня сбрасывается.

Новый наследник выбирается из кандидатов и начинает с Circle 1.

# 20. Победа

Победа наступает, когда один наследник проходит 10 кругов подряд и возвращается в аул после финального испытания.

Финальный смысл: путь больше не является кругом. Род выходит из проклятой пустыни.

# 21. UI MVP

Центр экрана: круговой путь и аул в центре.

Сверху: Запасы, Мудрость, Слава, номер круга.

Рядом с героем: Силы, Body, Mind, Spirit.

После круга: экран выбора личного апгрейда и карты.

После смерти: экран итогов, Последняя Тамга, выбор реликта.

На карте: иконки тайлов, реликтов и Последних Тамг.

# 22. MVP на 24 часа

12 клеток пути.

3 типа наследников.

4 ресурса: Запасы, Мудрость, Слава, Силы.

6 тайлов: Оазис, Юрта, Камень Тамги, Волчий след, Мираж, Буря.

3 синергии: Оазис+Юрта, Тамга+Буря/Дух, Волки+Юрта.

10 кругов.

Последняя Тамга и 1 реликт после смерти.

Простые stat checks без боевой сцены.

Один экран победы и один экран смерти.

# 23. Приоритет реализации

Карта из 12 клеток и автоматическое движение героя.

Ресурсы, Силы и смерть.

Круги и возврат в аул.

Выбор наследника.

Тайлы пустыни и их эффекты.

Карты после круга.

Личные апгрейды героя.

Последняя Тамга после смерти и её сбор.

Реликт после смерти.

Синергии тайлов.

Аул и постоянные апгрейды.

Финальное испытание 10-го круга.

# 24. Риски

Слишком сложная мета-прогрессия. Решение: на MVP только простые апгрейды.

Пустыня может стать несбалансированной. Решение: сбрасывать её после смерти.

Смерть может ощущаться наказанием. Решение: Последняя Тамга создаёт цель для следующего героя.

Игрок может не понимать синергии. Решение: показывать краткие подсказки на карточках.

10 кругов могут быть слишком длинными. Решение: короткий путь и ускорение анимации после первых кругов.

# 25. Тон и атмосфера

Не уходить в арабский “Алладин”-вайб. Держать тюркско-кочевой тон: аул, тамга, юрты, степь/пустыня, духи ветра, волк, сказители, память рода, путь, песня, старейшины.

Ключевой тон: меланхоличная, но не мрачная история о поколениях, памяти и пути.
