# 03. Системы

## Наследники

В MVP есть 3 наследника:

| Наследник | Роль |
| --- | --- |
| Охотник | Физические проверки, звери, волки. |
| Шаман | Духи, бури, священные места. |
| Сказитель | Миражи, руины, память, Последние Тамги. |

Числа берутся из:

```text
games/turkic-jam-2026/config/heirs.tsv
```

## Ресурсы

| Ресурс | Что значит |
| --- | --- |
| Запасы | Практический ресурс аула. |
| Мудрость | Знание пути, смертей и духов. |
| Слава | Имя рода и общий прогресс. |
| Силы | Жизнь/выносливость текущего героя. |

## Проверки

Опасные тайлы используют stat check:

```text
difficulty = base + per_circle * circle
```

Если стат героя проходит сложность - полная награда.  
Если не проходит - герой теряет Силы и получает часть награды.

Числа проверки находятся в:

```text
games/turkic-jam-2026/config/balance.ini
```

## Последняя Тамга

Когда герой умирает, на месте смерти появляется Последняя Тамга.

Это не пассивный бонус. Это цель на карте.

Следующий герой может дойти до этой клетки и собрать Тамгу. После сбора она исчезает и дает Мудрость и Славу.

Правила MVP:

- максимум 3 активные Тамги;
- новая Тамга появляется на клетке смерти;
- награда тем выше, чем дальше погиб герой;
- Сказитель должен быть лучшим архетипом для сбора Тамги.

## Реликт

После смерти игрок выбирает один тайл пустыни, который переживет сброс.

MVP-правило:

- реликт сохраняет тип тайла;
- реликт становится слабее;
- одновременно активен только 1 реликт.

Задача реликта - дать эмоциональную связь между забегами, но не сохранить всю пустыню.

## Аул

Аул - постоянный слой прогресса. Точнее, стартовая форма этого слоя - **стойбище рода**. Игрок начинает с маленького лагеря в пустыне, а в долгой мета-прогрессии выращивает его в политический и духовный центр.

Для MVP аул не должен быть отдельной сложной экономикой. Это набор простых улучшений:

- усилить Охотника;
- усилить Шамана;
- усилить Сказителя;
- сохранять больше Запасов после смерти.

## Прогрессия аула

Дальняя дуга меты:

```text
стойбище рода
-> родовой аул
-> укрепленный аул
-> торговое поселение
-> степной город
-> восточная столица
-> ханство / султанат / каганат
```

Смысл: игрок не просто покупает бонусы. Он видит, как память погибших наследников и ресурсы пути превращают маленький лагерь у костра в центр власти.

| Ступень | Визуально | Что открывает |
| --- | --- | --- |
| Стойбище рода | 2-3 юрты, костер, следы в песке. | Стартовые наследники, базовые карты, сохранение части ресурсов. |
| Родовой аул | Больше юрт, загон, место сказителя. | Выбор наследника, первые реликты, больше памяти после смерти. |
| Укрепленный аул | Вал/частокол, сторожевые огни, мастерские. | Подготовка героя перед выходом, стартовые Силы выше, защита от части провалов. |
| Торговое поселение | Караванная стоянка, рынок, водоем. | Обмен ресурсов, выбор 1 из 4 карт вместо 1 из 3, покупка/сброс карты. |
| Степной город | Улицы, святилище Тамги, ремесленные кварталы. | Синергии тайлов, 2 активных реликта, постоянные здания в центре. |
| Восточная столица | Купола/арки/архив рода без арабского клише, двор, сад/водоем. | Уникальные наследники, школы/ордена, сильные ветки карт. |
| Ханство / султанат / каганат | Политический центр, знамена, караваны, вассальные стойбища. | Глобальные эффекты на весь путь, endgame-цели, финальная кампания. |

## Этапы аула как крупные unlocks

Переход на новый этап должен ощущаться как большая награда:

1. Меняется внешний вид центра карты.
2. Добавляется одна крупная фича.
3. Открывается новый тип решений между забегами.
4. В логе/интро следующего наследника появляется новая формулировка статуса рода.

Примерная структура unlocks:

| Этап | Крупный unlock | Игровой смысл |
| --- | --- | --- |
| Стойбище рода | Сохранение части ресурсов после смерти. | Смерть не обнуляет путь. |
| Родовой аул | Выбор наследника перед стартом. | Игрок начинает планировать маршрут под героя. |
| Укрепленный аул | Подготовка героя: выбрать 1 стартовый бонус. | Забег начинается с решения, а не только с рандома. |
| Торговое поселение | Караван: обменять ресурс или заменить карту. | Игрок получает контроль над плохой рукой карт. |
| Степной город | Святилище Тамги: хранить 2 реликта/памяти. | Прошлые смерти сильнее влияют на будущие забеги. |
| Восточная столица | Школы/ордена: открыть ветки карт по архетипам. | Появляется стратегическая специализация рода. |
| Ханство / султанат / каганат | Вассальные стойбища: глобальные модификаторы карты. | Игрок влияет не только на один путь, а на всю пустыню. |

Для MVP нужен только первый unlock:

```text
Смерть -> часть ресурсов сохраняется в стойбище -> новый наследник выходит сильнее.
```

Для джема реализуем только первую ступень и намекаем на рост визуально:

- после смерти добавляется ресурс аула;
- в центре может появляться новая юрта/огонь/знак;
- death panel показывает, что стойбище стало сильнее;
- UI не открывает полноценный city-builder.

## Карты

Карты - способ занять пустынные ячейки.

После круга игрок выбирает одну карту из трех.

Типы карт:

- поставить тайл;
- улучшить тайл;
- улучшить героя;
- улучшить аул.

Для первого билда карты бесплатные. Экономику покупки карт не добавлять.
