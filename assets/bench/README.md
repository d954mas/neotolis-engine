# Benchmark Fixture Corpora (AUDIT-01)

Committed fixture corpora for the atlas packer benchmark
(`scripts/bench_atlas.sh` → `tools/research/atlas_bench`). They are the
reproducible inputs behind the baseline JSON of record
(`tools/research/atlas_bench/baseline/*.json`) that Phase 83 diffs against.

## Corpora

| Corpus | Files | Source / License | Packer profile | Purpose |
|--------|-------|------------------|----------------|---------|
| `anim_heavy/` | 30 PNG | Synthetic (this repo, CC0) | concave | Multi-frame sequences with byte-identical frames — exercises dedup |
| `anim_trim/` | 28 PNG | Synthetic (this repo, CC0) | concave | Post-trim-only and D4-orientation folding, as two separately measurable groups |
| `rect_only/` | 32 PNG | Synthetic (this repo, CC0) | rect | Solid opaque rectangles of varied size — pure rectangle-packing density |
| `slice9/` | 12 PNG | Synthetic (this repo, CC0) | concave | Rounded-corner 9-slice panels (transparent corners → real hulls) |
| *(mixed_aa)* | 4812 PNG | `assets/sprites/bigatlas` (reused) | concave | All-unique / mixed-AA corpus — **not stored here** |

The fourth AUDIT-01 corpus, **mixed_aa**, reuses the existing
`assets/sprites/bigatlas` set (per decision D-06) and is not duplicated under
`assets/bench/`.

## Provenance & license

All four committed corpora are **deterministic synthetic** fixtures generated by
`scripts/bench_gen_corpora.py` (pure Python stdlib: a raw `zlib` PNG encoder, no
Pillow/numpy). They are original to this repository and released **CC0 / public
domain** — no third-party assets, no license encumbrance. Deterministic decisions
in each corpus:

- `anim_heavy` — three sequences (`orb`, `spark`, `ring`). `orb` is 10 frames that
  resolve to **4 unique** frames (the Phase 82 "anim 10→4" dedup case); `ring`
  ping-pongs to 6 unique of 12; `spark` is 8 all-unique. Byte-identical frames are
  emitted from a cached render keyed on frame state.
- `rect_only` — 32 fully opaque rectangles, widths/heights spread across [8, 160].
- `slice9` — 12 rounded-corner panels of varied size / border / corner radius; the
  transparent corners give the packer a non-rectangular hull to trace.
- `anim_trim` — two groups the dedup counters can read apart. `trim_s*` is 4 art
  states blitted at 4 canvas sizes / offsets each: the untrimmed bytes all differ,
  so 16 → 4 placements is reachable **only** after the alpha trim. `d4_s*` is 3
  further states re-emitted mirrored and transposed inside a uniform 1px frame,
  so 12 → 3 placements is reachable **only** through the orientation search. The
  art is an F-shaped glyph — asymmetric under all eight orientations, so a fold
  can only happen through the one correct relative transform.

## Regeneration

```
python scripts/bench_gen_corpora.py            # writes assets/bench/{anim_heavy,anim_trim,rect_only,slice9}
```

The generator is deterministic (fixed layout math + level-9 deflate), so a fresh
clone reproduces the committed PNGs **byte-for-byte**.

## LFS note (finding)

`assets/` is **not** globally routed through Git LFS. Only `assets/sponza/**`
`.glb`/`.bin` were tracked before this phase — in particular
`assets/sprites/bigatlas` PNGs are stored as **raw git blobs**
(`git check-attr filter` reports `unspecified`). These bench PNGs therefore
required an **explicit** new rule in `.gitattributes`:

```
assets/bench/**/*.png filter=lfs diff=lfs merge=lfs -text
```

Do not assume `assets/` is LFS-backed globally. Verify a new asset path with
`git check-attr filter -- <path>` and `git lfs ls-files`.
