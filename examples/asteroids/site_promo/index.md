---
title: Methane Asteroids baseline
description: Source-derived Methane scene and benchmark workload, with 1,000–50,000 objects and original mesh, texture and LOD variation.
---

The original camera, Mars, Galaxy sky, procedural meshes and source workload are
translated to Neotolis C17/WebGL 2. Keys 0–9 select complexity; Ctrl+P pauses;
L shows LOD colors. The default is 2,000 objects, with an explicit 50,000 maximum.

The default native panel provides Settings, Statistics and Help. `--ui 0` keeps
the source-style HUD. Actual browser/device validation remains unverified. Retain the original demo and
image attributions with distributions.

Original [Methane Asteroids](https://github.com/MethanePowered/MethaneAsteroids)
by Evgeny Gorodetskiy, Apache 2.0. Mars by
